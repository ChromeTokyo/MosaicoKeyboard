# Chrome 独立复核：轨一托盘 v0.4-r2

**结论：CHANGES_REQUIRED。** 静态脚印和四角覆盖比 v0.3 明显改好，但默认件没有独立的插入止挡；插到底后的继续推力仍由 H2 排针／母座承受，不能称“排针只走电、不承力”。装拆时顶面尚未受压框约束，针尖接触前的新增导向仅 0.095 mm，真实针长与座口容差均未测。现阶段不应将这组 STL 当作用户到货即装的已验证件。

## 逐条硬伤与改法

1. **默认件没有把轴向载荷从连接器移走。** `extended_baseplate.scad` 的 `GAP=0.5`、`CLR=0.15`、外壳让位 0.2 只留下 `STOP_T=0.15 mm`，低于 1.2 mm 最小壁，故 `STOP_ON=false`（第 69、143–144、201–203 行）。[受审 README](https://github.com/ChromeTokyo/MosaicoKeyboard/blob/8b458ee/mechanical/quickstart/README.md) 第 9、47、76、87 行明言推进到 H2 排针座到底；Mosaico 前脸距模块外脸仍有 0.5 mm，托盘没有更早接触的止面。因此插到底后的 +Y 推力先落到 H2；反向退出时后裙还留 0.8 mm（SCAD 第 105–106、154 行），在它接触前亦由连接器抵抗。静态环形沿可承 Z 向重量，但**不能证明 H2 不承受日常轴向力**。闸门 #10 只 WARN，未阻断这个与 Q1 核心目标相反的状态。应让独立机械止面或可验证的限位／夹持件接管双向轴向力，并在闸门中把该载荷路径列为硬条件；若现有 0.5 mm 空间确实做不到，应修改结构方案与“只走电”声明，不能靠文字放行。
2. **插入和拔出时，排针先于可靠的三维导向承受误操作风险。** 受审 README 第 86–90 行的顺序要求 Mosaico 在压框未装／已拆时沿 Y 滑行；环形沿托底、两侧角柱限 X，却没有顶面 Z 约束，手一抬即可能边拔边撬针。名义针露长 6.0 mm 时，模块端角柱只早接触 `0.095 mm`；针露长 `6.2 mm` 时针已**早于角柱 0.105 mm**，我用完整闸门 `--pin-len 6.2` 复跑仍得到退出码 0、0 FAIL／3 WARN。闸门 #11 以 `1.22 < 1.27 mm`（半针距）视作横向偏摆未超阈值，但半针距并不等于单孔入口公差；座口实际导入尺寸未知。应测实物针长、针截面、座口及装配高度，设计有足够提前量的 X/Z 机械导向或临时插拔夹具；在完成前把这一步标为高风险手动试配，禁止以“轻推／目视”当成防错结构。
3. **防晃胶带建议可使玻璃先承压。** SCAD 第 146–148 行给出的压边底 Z=11.60、假设屏面 Z=11.48，名义游隙仅 `0.12 mm`；受审 README 第 92 行却建议在四边压边下贴 `0.1–0.2 mm` 胶带，并只警告 `>0.3 mm`。贴 0.2 mm 会产生名义 `0.08 mm` 的几何压缩；胶带的压缩力未知，压框可能先压玻璃才坐柱顶，原本“螺钉力全进立柱”的结论不再成立。应先删去该用户操作建议；若需要消晃，待实测 Mosaico 厚度、胶带压缩特性和止点后另定厚度及装配检验。

## 已核到的几何与尚需试件验证的风险

- **四角静态包络：** 四根立柱的内侧从 X=±22.745 向外，Mosaico 名义外侧 X=±22.595，单边间隙 0.15 mm；压框内窗 X=±21.595、Y[−67.14,−23.95]，相对 45.19 mm 方形本体四边各盖 1.0 mm。柱顶 Z=11.40，压边底 Z=11.60，名义竖向游隙 0.12 mm。STL 截面支持这些数字，不能据此推断打印后四角对任何载荷都不翘。闸门给出的适用厚度仅 **11.30–11.65 mm**；AS-01 的 11.48 尚未实测。
- **压框模块端的薄边：** 在压框 STL 的 X=0 截面，+Y 连筋宽约 **1.20 mm、有效厚约 1.40 mm，跨内窗 43.19 mm**。闸门 #4 测的是覆盖位置，#9 测的是最小壁／悬空，并未测试这条筋的受力变形或断裂；README 自身已承认它容易碰断。打印后须以实际受力和反复装拆验证，不能把几何“100% 盖住”写成受力“不会翘”。
- **打印边界：** 闸门确认托盘与压框 STL 封闭、名义最小壁和 2 mm 悬空限制通过；未证明 100.5 mm 长托盘／45 mm 跨的压框不翘，也未给出 0.4 mm 喷嘴下 Ø1.7 mm 底孔的实孔径。实孔径无法从 STL 单独推出；先同批打印四孔校准件，量孔径及 M2 自攻开裂／保持，再打印整件。四颗螺钉盘头在模型中约高出屏面 **2.69 mm**（脚印外），是否可接受须由用户对操作与碰触确认。
- **官方件避让：** 按归档的官方底板／外壳网格，压框距外壳名义约 **0.30 mm**；GAP 区 Z=2–9 mm 对排针留空，两个键盘轴在模块区，未见可证实静态干涉。此结论只覆盖网格与假设装配姿态。官方外壳卡合弹性、PCB/排针的真实高度、Mosaico 背面凸起与打印变形未用实物或制造公差证实；0.30 mm 余量须试配。

## 闸门漏洞与我没核到的

- **失效可静默跳过：** 将 `--shell /tmp/this-shell-file-does-not-exist.stl` 交给完整闸门，仍退出 0 且 #0/#2 PASS；脚本第 315–322 行把不存在的外壳置为 `None`。外壳被要求核对时应缺件即 FAIL，报告也应显式显示使用了哪个官方网格及哈希。
- **危险运动学仍可全绿：** `--pin-len 6.2` 让针先碰 0.105 mm，完整闸门仍 0 FAIL。#11 第 1178–1198 行只 WARN，且把“未超过半针距”作为安全阈值；应改为依据已测座口入口尺寸和规定导向提前量判，未知就不能自动 PASS。
- 未核到：实物 Mosaico／官方模块的尺寸、玻璃到边与圆角、背面凸物、针露长与 H2 入口、插拔力、PCB／外壳实装、打印试件孔径／翘曲／疲劳、螺钉力、官方材料和真实跌落／按键载荷。此报告是非作者的桌面复核，不替代用户试装或后续规定的硬件放行。
