# C3：H2 底座触点逻辑表与落座扫掠阻断（2026-09-24）

**默认只需 12 颗底座触点：十键、H2 pin17 `5V_IN`、pin20 GND。** 但这只是逻辑脚位表；现行“−Z 压入、+X 接触”的动态电气安全尚未证明，**不得**据此生成可制造封装、通过错位闸门或给主板上电。依据是[左槽 20 脚合同](../D1-module-interface/LEFT_SLOT.md)与[十键静态表](../../../firmware/dock_handle/include/dock_handle_pinmap.h)，实际 pin1 在 +Y/−Y 与两排前后顺序须由 U3 到货记录确认。

| 同一 Y 站位 | 奇数针：主机网络 → 底座用途 | 偶数针：主机网络 → 底座用途 |
| --- | --- | --- |
| 1 | p1 GPIO55 → UP | p2 GPIO53 → A |
| 2 | p3 GPIO19 → DOWN | p4 GPIO48 → B |
| 3 | p5 GPIO18 → LEFT | p6 GPIO13 → X |
| 4 | p7 GPIO17 → RIGHT | p8 GPIO12 → Y |
| 5 | p9 GPIO16 → L | p10 GPIO14 EEPROM A0 → 不装 |
| 6 | p11 GPIO15 → R | p12 GPIO4 备用 → 不装 |
| 7 | p13 USB D− → 不装 | p14 I²C SCL → 默认不装 |
| 8 | p15 USB D+ → 不装 | p16 I²C SDA → 默认不装 |
| 9 | p17 `5V_IN` → 电源一针 | p18 `5V_OUT` → **不装** |
| 10 | p19 主机 `VCC_3V3` → 默认不装 | p20 GND → 回流一针 |

默认奇数 7 颗、偶数 5 颗，共 12 颗。SCL/SDA/3V3 不是十键必需；若后来要求可分别在 p14/p16/p19 增加触点，但**不得**把 p18 输出接到底座 5V。全 20 根直排针尾即使底座只装 12 颗也都暴露，省掉 p18/p19 底座触头并未给它们绝缘。电源单针额定仍以 H2/p17、pin20 和实物为未知，不能套用排针自身的额定。

## 坐标只到逻辑相对量

把站位 `k=1…10` 暂写为 `(2k−1,2k)`；站位中心沿 Y 相隔 2.54 mm，两排沿 Z 相隔 2.54 mm，长度中心距 `9×2.54=22.86 mm`。`pin1` 在 +Y/−Y、奇数排在 +Z/−Z、首站的绝对 Y/Z、针尾 X 面、PCB −X 边缘、触点本体与焊盘朝向、最小电气间隙均**未确定**。V1.0 引脚表和 V1.2 外观照片不提供这些定版坐标。C2 尚无合格侧擦触点，故不能交付真实 J2 footprint。

## 静态不桥接 ≠ 插入过程无错接

理想 Ø0.9 mm 圆触头、0.64 mm 方针尾：方针与圆头的最大径向触及 `0.64/√2 + 0.9/2 = 0.9026 mm`，小于半间距 `1.27 mm`，故在刚性、只碰**端面**的模型中一头不能**同时**搭相邻两尾。若方针对阵列轴正交，一维触及仅 `0.32+0.45=0.77 mm`；任意转角/最坏一维可到约 0.903 mm，因此第一根邻针可能在位移 `2.54−0.903≈1.637 mm` 时已被碰到。旧[方案 J](../../claude/option-j-seated.md)写的 0.77/1.77 mm 不是通用旋转方向上界；实际 C1 样件 0.63 方针仍要加针宽、触头尺寸、针位、倾斜、弹性变形与装配公差。

更严重的是**整机沿 −Z 入仓**。假定两排恰沿 Z 排列，Mosaico 在靠近最终位置的最后 2.54 mm 移动时，正在供电/接地的底座触头可能先扫过另一排同站位尾端：

| 尚待 U3 确认的行顺序 | 可能先碰的错针 | 关键后果 |
| --- | --- | --- |
| 奇数排在 +Z（靠前） | 奇数底座触头扫过偶数主机尾；p1→p2、p3→p4、p5→p6、p7→p8、p9→p10、p11→p12、**p17 的底座 5V→主机 p18 `5V_OUT`** | GPIO 键串扰；5V 输入可能送入主机的**输出**网，实际内部反向路径未知，不能称安全 |
| 偶数排在 +Z（靠前） | 偶数底座触头扫过奇数主机尾；p2→p1、p4→p3、p6→p5、p8→p7、**p20 底座 GND→主机 p19 `VCC_3V3`** | GPIO 键串扰；3.3V 输出可能被短到地，需视为上电阻断 |

这只说明**若在该段 Z 行程已发生 X 接触**时存在错接窗口，不声称实物必然触碰。若不同结构让触头直到坐底后才沿 X 伸入针尾轨迹，就可规避该窗口，但现行描述、C2 料号和 M5 公差表尚未证明存在这种隔离。拔出沿 +Z 会经过反向同一窗口。若加装 p14/p16/p19，还会出现 SCL→USB D−、SDA→USB D+、3V3→GND 等新窗口；静态导向容差也须对 p17 与 p15/18/19/20 等全邻位枚举。端面以外碰针身/塑料或滑擦侧力亦未由上式排除。

**闸门要求：** 原 [`check_j2_mismate.py`](../../../hardware/check_j2_mismate.py) 是废弃 4×4 场的静态模型；只把参数换成 0.64/0.9 跑到退出 0 会制造假安全。M6 应先建真实 YZ 方针/触头、X 接合时序和 −Z 全行程扫掠模型，再用实物断电逐步导通验证；尤其两种行朝向都要测，再固定实际那一种。测试故意留可预期的“阻断”用例直到证明不会错接，随后才可让真正的新闸门为绿。H2 在滑擦时的 Z 向摩擦剪力也须由 M1/M5 的壳体路径或实测封闭。
