# D4：模块板/底座板断电逐点通断规程（待审）

2026-09-23 JST。用途是在**任何 USB、电池或 Mosaico 主机接入前**，用万用表发现模块板和底座板的 180° 旋转、镜像、列行重排或针序错配。此为将来样板的检验方案，**未执行、未放行**。4×4 示意表取自待审 `origin/claude/design-d/module-board` `94e393c` 的 `hardware/module-board/PINMAP.md` 修订 c；它与该分支 `netlist.yaml` 仍为 **2×8、Ø1.8 mm** 的电路源矛盾，和 main 的旧 ICD 也不同。先在同一提交冻结实际网表/PCB/焊盘号与机械图，再印此表作为该版本检验单；在此之前不能按下表打板或通电。

## 工具与留证

- 用户已有的万用表（通断/电阻档）、绝缘垫、纸质方向标签、手机相机；必要时由工厂提供带网名的大测试点治具。**不要用万用表尖端跨越 2.54 mm 的相邻裸焊盘**；尖探针必须绝缘包覆到尖端，只露测点。
- 给模块板、底座板各拍正反面及装配面对齐照，标出板号/修订、J1/H2 的 **pin 1**、屏朝向、原生 USB-C 朝下、+X/−Z、J2 **列1/行D**。每张照片放毫米尺或卡尺固定挡块作比例，并同屏写样板编号、日期和检查人。正视/底视必须标明，不让“左上角”代替坐标。
- 记录万用表型号、档位、短接表笔基线电阻；低阻值扣除表笔电阻。输入是**实际焊后的板**及其同 SHA 网表/PCB，不能只测 CAD 导出或裸 PCB 中一者。

## 断电检查顺序（任何一项异常即停止，不接主机/电源）

1. **彻底断电并核零压。** 底座电池插头拔开，两根 USB-C 都拔下，Mosaico 不插模块板；量 `DOCK_5V`、`SLOT_3V3`、`VBAT` 对 GND 均已放电到接近 0 V 后，才用通断/电阻档。不要靠“LED 灭了”判断断电。
2. **单板逐网查。** 模块板接点 `J2` 与 H2 焊盘逐点核对下表。5V 两点应只到 H2 pin17；GND 四点应只到 H2 pin20；十条 KEY 各到指定 H2 针，若焊装串阻则按实装 BOM 的标称阻值读电阻，不能把不响蜂鸣器误判开路。每条再抽查对**相邻不同网络**无意外连通。`J2` 不应有 SDA/SCL 或 3V3。H2 pin18 `5V_OUT` 焊盘对 J2、pin17、pin19、GND 及其它信号均应开路；pin19 只给 EEPROM 一侧，不接底座供电针。5V/GND 之间应无稳态低阻短路，给电容充放电的瞬时读数不能当短路结论。
3. **底座板独立查。** 在不接电池/USB 时，逐个弹簧针到其底座网络测试点或开关端测接线，记下实际网名。限流及防反灌器件可能使断电时输出至升压端呈开路，故**不能**用“量不到 boost”否认输出针网络；使用限流后的 `DOCK_5V` 测点、制造网表与板上丝印交叉确认。按键针只能到对应无源开关，不得接任何电源/上拉；各电源针间无焊锡桥。
4. **面对面无电配对。** 先用方向照片确认两板的物理 (X,Z) 坐标一致；触点板底视与底座顶视的图像会左右翻转，严禁直接把两张照片的“左上”互对。用隔离治具使两面名义落座，逐位核 `DOCK_5V` 对 `DOCK_5V`、GND 对 GND、十键各对同名键；记录每个通路的电阻和至少一张对齐照片。拔出后重查两板无短路。任何绕 Y 轴 180°、底视/顶视镜像或错一行/列的可接触姿态，须记录它能否物理落座及何时电接触；不能只凭脚本“正确方向 F=0”就判误装安全。
5. **交给非作者审查。** 附原始 16 行电阻记录、实际网表与 PCB/Gerber 同提交号、焊盘坐标/面向图、万用表及样件编号。Hiro/Grok 审完并确认主机侧 pin17/18/19 电源边界、输出限流、机械防呆和 G2 间隙后，才可进入受控假负载/分步上电。此表通过本身不准直接给 Mosaico 通电。
