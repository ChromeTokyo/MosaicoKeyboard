# D1：V1.2左槽接口核查交付

2026-09-20；Chrome / Codex / gpt-6-astra / ultra。仓库输入 `ff24626`；BSP固定 `392860b1d1a123c3377947074b2af1f600e86c5d`。状态 **IN_REVIEW**，这是资料研究交付，不是电气/机械冻结或样机通过。

## 结论

1. **方案D可以继续电路草案。** 左H2有12根通用GPIO，其中GPIO14连接EEPROM A0须保留，余11根足够10键直连；与板载I²S五脚无交集。完整20针、证据位置及方向限制见 [LEFT_SLOT.md](LEFT_SLOT.md)。不需要为此引入第二颗MCU或I/O扩展器；R04文字由用户/主控处理。
2. V1.2的GPIO0/1属于模块专用I2C1；主板在GPIO56/3，不能再套用V1.0共享地址/上拉网络限制。0x50/0x51仍归左右槽EEPROM；实际外部上拉、电源断开容限及其他模块并存状态待核。
3. 标准模块AT24C02 A0接H2 pin10/GPIO14，左地址0x50；模块管理器以100kHz、单字节内部地址0连续读134字节，验证ASCII ESP、三个CRC16和参数长度。完整原始布局、默认250ms/3次发现去抖、claim/release及驱动接入边界见 [BSP_AND_EEPROM.md](BSP_AND_EEPROM.md)。**空白EEPROM不合格，烧入合法身份也不会自动产生十键驱动。**
4. pin17为底座5V输入到主机，pin18是主机输出，本方案不接；pin19为主机3.3V供EEPROM，pin20地。**底座供电不能等EEPROM识别、GPIO60或MCU判断**；主机可能需先得到pin17电源才能启动和扫描EEPROM。
5. [5V路径与版本证据边界](DOCUMENT_BOUNDARIES.md)：V1.0原理图可追到D10/VCHG/板载充电器及D15/VSYS；**V1.2具体内部位号、保护和额定仍unknown**。官方1.2.1+扩展指南不含该电路/额定，不能借用100mA模块输出或500mA USB source做pin17输入额定。

## 设计与后续交接

- D2选支持3.3V、256×8、硬件A0、单字节地址和134字节顺序读的24C02；须准备安全独立烧录接口，WP策略、身份字段、CRC生成/回读及主机测试程序。管理器没有写EEPROM API。厂商/板ID未分配，不套用官方量产模块身份。
- 主机侧十键驱动应固定左槽、声明资源、响应拔出并释放GPIO/lease；普通按键输入无需复用GPIO14。应用完整实现后排期，但G6所需最小测试固件应发运前完成。
- 新发现的物理限制：V1.2槽外部I²C上拉待实测；pin17及单pin20回路额定未知；GPIO60不做安全隔离。热插拔软件支持不是接触次序/浪涌安全证明。
- 待实物：记录CoreBoard/BSP检测版本、BaseBoard标识、H2 pin1朝向；先无源配对和审核后的限流验证，核电源四态、I²C波形、EEPROM读出/CRC、十键映射与音频并行。
