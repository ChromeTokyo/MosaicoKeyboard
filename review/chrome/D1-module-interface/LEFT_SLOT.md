# D1 左槽引脚合同（草案）

输入BSP固定提交 `392860b1d1a123c3377947074b2af1f600e86c5d`。引脚编号是**主机左槽H2**针号，不是GPIO号，也不是从任意照片左到右的序号。证据快照与SHA256见 `evidence/bsp/SOURCE_INDEX.json`；BSP含V1.0/V1.2分支。H2针号与官方V1.0引脚表交叉一致，V1.2实物的方向、键位、接触和供电额定仍须实测。

**ASSUMPTION: A-H0-1（Hiro H0 F06）**：下表将 V1.0 官方 H2 针号文字与固定 BSP 的 V1.2 GPIO 映射合成 V1.2 工作合同，假设 V1.2 实物逐脚铜线、5V_IN/OUT 方向、3V3 输出及连接器朝向均与该合同一致。BSP 只能证明软件映射，V1.0 图只能证明旧版；同名外壳标记不是 V1.2 电气实测。到货后记录板号，以限流电源、断电通断和插接方向逐脚核验，并由非作者复核后关闭。下表各 GPIO 是源码可核的软件事实，V1.2 物理连接仍是本假设。

## V1.2的I²C与电源状态

`esp_mosaico.h:62–75`及`subboard.c:73–98`：V1.0复用主板I2C0；V1.2主板用GPIO56/3，模块用GPIO0/1的独立I2C1。主板地址0x11/12/19/55/5A/69不再占用模块这条总线；模块EEPROM保留0x50/0x51，实际另插模块的地址仍须管理。**不得照搬V1.0的4.7k/Codec2.2k上拉结论**。V1.2源码开启内部上拉，不能据此判定外部上拉是否存在或是否足够；保留外部上拉DNP选位，按实物电阻、总线电容与边沿复核后决定装配。

所有逻辑按主机3.3V域设计，禁5V上拉；按键拟无源接地，拉高来自主机侧，EEPROM从pin19取电，避免底座电池仍有电时向掉电主机注入电流。串阻/ESD/断电容限仍属下一阶段电路审核。

`subboard.c:122–141`在扫描前先开启主机模块VCC_3V3，再初始化I²C，再把左GPIO14设为输出0、右GPIO39设为输出1。因此**pin17供电不能等待EEPROM识别或主机GPIO许可**，否则主机电池耗尽时会形成启动循环依赖。GPIO60是主机模块输出控制，不作为底座升压使能。

**Hiro H0 F07 后续接口合同：** 底座经 pin17 的电源路径还须在原生 USB 同时供电、底座电池或 USB 缺失、主机关机/内置电池耗尽、底座输出禁用或故障时保持硬件限流与反灌隔离；pin18 NC、pin19 不反送。D/B/N 八态及叠加态、测试点和未决额定见 [D3 电源拓扑复核](../D3-power/TOPOLOGY_REVIEW.md)。此为设计约束，不代表 V1.2 内部合并网络已查明。

电源内部实现和版本边界见 [DOCUMENT_BOUNDARIES.md](DOCUMENT_BOUNDARIES.md)。EEPROM格式及驱动绑定待同目录后续报告；本文件不冻结任何网络/封装/接插件方向。
