## 模块 pin17 的使用合同与电路实现应分开

- 固定提交的官方 V1.0 指南 H2 左槽表，`user_guide_v10.rst:651–653`，pin17 = 5V_IN，功能是外部5V供电并给设备充电；pin18是主机5V输出（:660–662）。这符合用户指定的方案D电源方向。
- V1.2 的槽位引脚后续与BSP逐项交叉核对；BSP可以证明软件映射，不能证明铜线、保护器件与额定电流。主控记录的新外壳标签与旧表一致是额外线索，尚不能代替完整V1.2电路图。
- 已归档 CoreBoard **V1.0** 原理图 p3 CN3：5V_IN在45/47/49/51；p5：`5V_IN → D10 → VCHG/VBUS_IN`，再分流至U23 TP4057为内置电池充电，以及`D15 → VSYS → Q2.1 → VDD`为整机供电。D9为检测分支，不是主负载串联通路。详见前次[T04逐图证据](../T04/COREBOARD_INTERFACE_EVIDENCE.md)。
- **上述具体位号、并联BTB针数、压降与保护链仅证实于V1.0。** 新扩展PDF未披露V1.2 BaseBoard/CoreBoard电路，不能宣称V1.2逐网相同；pin17至主机电源/充电功能为工作接口合同，内部实现继续unknown。
- USB source 500mA／超1A断电，以及模块向外输出5V/3V3各100mA，都不是pin17输入额定。**pin17安全连续／峰值电流、输入电压容差、热插拔浪涌和双电源反灌边界仍unknown**；不推算数字来关闭。
- pin18始终不接底座供电输出。GPIO60控制不能当作硬件隔离保证：V1.0原图还有USB到5V_OUT的D14旁路；是否沿用V1.2未知。pin19用于主机侧供电的EEPROM候选，不能由底座强送3.3V。
