## 与当前设计的关系

1. **先确认版本，再决定触点。** 到货先拍包装、完整背面、两侧接口、可见的版本丝印；板号藏在屏幕后面就记“不可见”，不为认版本拆屏。记录CoreBoard与BaseBoard各自版本，不能只填“ESP-Mosaico”。
2. **A（四焊盘）成为明确的条件分支。** 只有到货确实存在并核实那四个焊盘时才继续。若与视频V1.2一致，当前A缺少可见接口，暂停A的Pogo几何与供电映射；这不推翻Fig.7本身，也不证明用户所购必是V1.2。
3. **B分清薄片／外盖与BaseBoard。** 可接触焊点的可能性增加，但“孔就是Pogo靶”仍不成立；不自动拆除带电池和扬声器的BaseBoard。
4. **C仅提出研究方向：** 保持整机完整，通过侧面插座做可拆转接，并考虑侧向占位与抗拔承力。需匹配到货版本的pinout、电源规格和机械路径，尚未选定、未替代A/B裁决。后续T03/T05可并行比较，PCB继续不冻结。
5. **重核跨版电气假设。** T04已有V1.0来源不删除；T05/T07在获得目标版原理图或足够实测前，不把V1.0上拉、电源保护和共享GPIO直接当作目标版事实。视频里的电池标签与65mAh量级相容，也不能据此证明所有电源电路相同。
6. **3mf来源修正沿用主控PR #10：** 主控已依据官方账号评论确认其官方来源；此前Chrome文档的“来源未核实”随本轮更新。适用裸板组件还是完整白壳、是否匹配视频版本，仍需单独确认，不能从视频结尾认领任意同名文件。
