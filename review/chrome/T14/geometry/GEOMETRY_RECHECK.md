本图确认右侧两列**各恰有 10 孔**；逐行水平列距为 82.028–82.459 px，配对孔的垂直错位为 0.115–0.857 px。实际相邻焊盘水平推导值依次为 2.51448 / 2.51440 / 2.52164 mm；这些多位数字仅保留计算可追溯性，显示在用户尺寸表时不得表现为已达到微米精度。

两个需反馈主控的代码限制：

1. `grid_pitch` 文档写“严格提取两列各 10 孔”，但程序只要求每列不少于 3 点；用于其他图片时不会自动拒绝错检数量。本次附加检查已明确断言 `[10, 10]`，所以没有把该风险当作本图失败。
2. “直径”仍用 `(宽像素 + 高像素) / 2 / 水平标尺`，把两个方向混到一起。此图平均宽 51.25 px、平均高 49.00 px，分别按各轴标定得到 **水平 1.583 mm、垂直 1.608 mm（均 derived）**。它们只是颜色分割外包络的估计，仍不能作为保证可落针的有效金属面；但已说明原样输出 1.548 mm 不是严格的分方向直径。接口直径继续填 **TBD／待实物**，不采纳单一“约 1.55 mm”用于针头或公差链。

主控 README 所称“三项独立证据”包含同一图的两个统计及另一同源图；这些可以交叉发现方向性错误，但不能算三次独立实物测量。当前记录只核验已提供的这一原图，不声称复核了未附执行记录的另一同源图。

## 4. 更正后的布局研究预留

所有数字在本节均为 **proposed 研究设置**，不是实物误差或制造公差。

- 可恢复 `p = 2.54 mm` 作为明确标注 `POGO_GEOMETRY_UNVERIFIED` 的研究初值；不能视为冻结。参数仍允许 `p12 / p23 / p34` 独立变化，保留整排的平移与角度，待实测决定是否等距。
- 旧版由错误间距推导的额外末针补偿全部删除。不再据该图要求放大针间距或外移末针。
- 建议研究夹具采用可更换四针载板／载体，整排在 X、Y 两方向各留 **±1.0 mm 调试行程**。这是主动选择的调试空间，不是从照片推导的尺寸保证；实际绝对位置若超出行程就改夹具，不让弹针强行偏心接触。整体平移不能补偿间距错误，故四针载板必须可重做。
- 禁布区还要包含针筒、焊盘、载体固定、绝缘和走线；上述外形全为 unknown，不能用 ±1.0 mm 直接推出 PCB 禁布框或外壳开孔。布局应参数化，T10 不冻结。

最终逐针核对 `总定位误差 + 针尖有效接触半径 + 边缘裕量 ≤ 焊盘有效金属面半径`；高度方向另算工作压缩量、硬限位和累积公差。该公式中的尺寸、公差、针型与裕量当前均未确定。把照片推导与两位小数显示误认为公差会重现本次问题。

## 5. 对 T14 用户规程的保留建议

1. **先拍方向再量。** 整机六面、背面四触点丝印、USB-C 与电源键位置同组留证；同帧放方向纸签。保留未镜像、未透视拉正、未截图压缩的原始照片。
2. **金属卡尺只夹安全外壳表面。** 关机、拔 USB 不代表内置电池已隔离；卡尺不得跨接／触碰裸露焊盘、通孔或器件。触点先用非接触近照量，计算由 Chrome 完成。未证明断电前不使用通断／电阻档。
3. **实体比例尺与触点等高、同平面。** 标尺放在独立支撑上，不压电路板；水平与垂直两个方向都留参照。金属尺不可悬在裸露电路上方。桌面上的尺不能直接标定更高位置的触点，也不能用后期叠加网格替代实体参照。
4. **分别标定 X/Y。** 相机正对，支架固定、散射光；建议 10 mm 标尺至少占 500 个原始像素（proposed 采样要求，不是准确度保证）。至少三次重新摆放／对焦，保留相邻三个中心距与首末跨距，逐盘水平宽／垂直高分别量；不再用一个不分方向的比例尺处理全部图像。
5. **记录量具真实条件。** 用户写型号、标称准确度、卡尺清零照片，安全外壳尺度各量三次供交叉核查；0.01 mm 显示分辨率不代表该测量准确到 0.01 mm。不共面外壳尺寸不能自动作为焊盘面的精密标尺。
6. **高度独立记录。** 拍清支撑面、外壳面与触点面；斜照片不能决定针的工作行程。照片质量／同平面参照不足时允许标“需补测”，不强行关闭 O01。

## 6. 方案 B 的实物条件

官方指南确认左右模块接口为 `2 × 10P / 2.54 mm`，但未保证通孔背面可作 Pogo 靶面。[官方 Module Interface](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s31/esp-mosaico/user_guide.html#module-interface)

必须实物核实：逐孔是否空心／填锡／有突出焊脚、侧向连接器占用、环形金属面内外径与高度、相邻导体间距、螺丝和背部结构能否非破坏拆装、拆后承力与绝缘／电池保护、导热材料及温升变化。用户只拍照和记录，不探孔、不拆焊、不撬胶粘件、不拉 BTB 或排线。针尖落在孔中央可能没有平面接触；不规则焊锡也不能当作保证高度的靶面。
