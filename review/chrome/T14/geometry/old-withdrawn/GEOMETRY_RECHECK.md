## 2. 旧 2.54 mm 方案偏移与研究余量

以下计算仅用于评估旧占位模型要释放多少空间，所有机械数字均为 **derived** 或 **proposed**，不进入制造坐标。

旧四针中心跨距为 `3 × 2.54 = 7.62 mm`。照片推导首末跨距为 `8.10–8.32 mm`，因此：

- 若首针位置不变，第四针需沿排列方向移动约 **0.48–0.70 mm（derived）**。研究布局应至少允许末针中心比旧方案外移 **0.70 mm（proposed，取已知差值上端）**；这只是覆盖本次图上差值，不覆盖未知定位偏差。
- 若保持整排中心不变，两端中心相对旧方案分别外移约 **0.24–0.35 mm（derived）**；研究布局两端各释放至少 **0.35 mm（proposed）**，不能把这个数当作装配允许偏心。
- 研究参数可暂用 `p = 2.735 mm`（范围中点，**proposed**）展示外形，必须标 `PHOTO STUDY / NOT FOR FABRICATION`。权威参数应允许 `p12 / p23 / p34` 分别填写，避免实测尚未证明等距就写死均布约束。原 A0 2.54 mm 不继续作为有效候选值。
- **proposed：** 四针使用可更换的小载板／定位载体，研究夹具给整排沿排方向与垂直于排方向各 **±1.0 mm** 的平移调试行程。这个数是便于装配验证的设计预留，未由照片证明“足够”；绝对位置、壳体基准和实际落点确定后重新审核。整体平移不能修正针间距错误，因此小载板必须能重做间距，不能仅开长孔保留旧四针封装。
- 不能仅把上述平移行程加到针尖外轮廓就宣称得到 PCB 禁布框。针筒、焊盘、载体固定、绝缘间距和走线尺寸均仍 **unknown**。先保留参数化接触区与可移动电路分区，选定针型和实测后再定义禁布外包络。

最终落点需逐针满足横向误差预算，例如 `总定位误差 + 针尖有效接触半径 + 预留边缘裕量 ≤ 焊盘有效金属面半径`。这里的总误差包括模块定位、焊盘位置、PCB 与载板装配、针偏摆、壳体加工及磨损；多项系统误差不能因为“平均可抵消”而删掉。上述半径、裕量和最终误差上限当前均 **unknown**；不能拿 1.66 mm 摄影直径直接宣称任何已选弹针可用。

## 3. 交给用户执行的测量要点

1. **先拍方向再量尺寸。** 记录整机正面、背面、上／下／左／右六面；背面近照能读四触点丝印；同帧放方向纸签，拍下 USB-C 和电源键的实际位置。原图保留，禁镜像、透视拉正、截图替代。底座顶视应镜像为 `SCL / − / + / SDA`，工程师按有标记的实物照片核对，不要求用户靠记忆翻转。
2. **卡尺只夹外壳安全表面。** 关机、拔 USB 不能证明内置电池已断开；不让金属卡尺跨过／触碰任意两个焊盘、通孔、器件或螺丝周边线路。四个小触点优先以非接触近照测量，实物中心距计算交 Chrome 处理。未确认电池已隔离时，不执行通断／电阻档。
3. **比例尺与焊盘在同一平面。** 把实体细分刻度尺放在触点旁的独立支撑上，刻度面与金属触点面等高，不压在电路板上；水平、垂直方向都留下标尺。尺放桌上而焊盘高出桌面会产生比例误差。金属尺不得伸到电路板上方；不能只用后期叠加的网格或打印时被缩放的尺作为基准。
4. **相机正对，原始照片足够清楚。** 使用固定支架、散射光，尽量避免超广角与数字放大。建议在四盘近照中，10 mm 刻度跨度至少占 500 个原始像素（约 0.02 mm/px，**proposed 图像采样要求，不是测量精度保证**）；若拍不到清晰刻线与触点边缘，标“需补拍”，不猜中心。
5. **每组至少三次重新摆放／对焦后拍摄（proposed 复测要求）。** 必须同时记录三个相邻中心距、首末中心跨距、四盘各自直径，以及整排对已定义壳体基准的 X/Y 位置。让 Chrome 在原图上给出读数和不确定度；用户记录量具型号、标称准确度、卡尺清零照片和原始尺寸，不把 0.01 mm 显示分辨率当成 0.01 mm 准确度。
6. **卡尺独立核对外壳尺度。** 可安全夹取的壳体直边宽／高各量三次，同一照片同时显示该壳体和同平面标尺。这能发现明显缩放错误；外壳与焊盘不共面时，该外壳尺寸本身不能充当触点平面的精密标尺。只有照片、没有可追溯参照或足够精度时，允许登记“未解决”，不强行关闭 O01。
7. **高度单列。** 要记录安装状态、测量支撑面、外壳背面和焊盘面相对位置。不能用模糊斜照估弹针压缩量；针高、工作行程、硬限位、总弹力和支撑路径在实测＋针型确定后共同计算。

## 4. 方案 B：通孔不能自动当作可靠 Pogo 靶面

官方用户指南确认左右模块接口为 `2 × 10P / 2.54 mm`，并给出模块信号与供电定义；它没有保证量产实物的通孔背面可作垂直接触靶面。[官方指南，Module Interface 与 Back](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s31/esp-mosaico/user_guide.html#module-interface)

B 方案的落针位置和弹针形状必须等实物；照片可见环形孔不等于实物裸孔。检查项目：

| 实物项目 | 用户可记录的证据 | 对方案 B 的影响 |
| --- | --- | --- |
| 孔是否空心、填锡、突出焊脚或焊锡尖 | 无触碰的正面近照＋侧面低角度照，逐孔编号，不用针探孔 | 空心孔中央不是平面靶；针尖可能落入孔；不规则焊锡也不保证一致接触高度 |
| 侧向连接器是否占用或挡住背面 | 整体和两端侧照；记录所有已装连接器，不拆焊 | 可能无法接近或与针筒／定位载体干涉 |
| 环形金属面外径、内孔径、最窄环宽与周边间距 | 同平面标尺近照；工程师测量，保留 unknown 项 | 决定针型、允许横向误差与避免跨接相邻焊盘的条件 |
| 背板拆装能否反复非破坏完成 | 拆前与每一步照片；螺丝位置／长度分开；遇胶粘、排线、阻力立即停 | 不默认可逆；不得撬屏、拉线、压电池或移除胶粘件来完成检查 |
| 拆背板后 PCB、连接器与电池的支撑／绝缘 | 原支撑、螺柱、垫片／导热材料位置照片；部件移动情况 | 外壳必须重建承力和防短路保护；不能让弹针总力弯板或挤压电池 |
| 拆前／拆后结构与散热变化 | 先记录材料与覆盖情况；通电温升验证留待有审核规程时 | 缺少受控温升与装配验证时只能记未知，不能凭“敞开更散热”判通过 |

**建议：** A 为更少结构改动的继续研究基线，B 为待实物证明可重复接触的候选。B 不必一次启用 40 个通孔；必要信号、总弹力、回流和可维修性需要一起设计。不得因多了 GPIO 就预先选定 B，亦不得以 B 未证实为由冻结 A。
