# 方案 J「落座式」—— 当前唯一在推进的架构（2026-09-24 版）

**这份文件是架构的唯一权威描述。** 其余文件提及架构一律指向本文，不得各自复述。

> **版本说明**：09-21 版描述的是「Mosaico 从上方沿 −Y 落入、两板 L/T 形转接件、J3 接头」。
> **该版已于 09-23～24 被用户的三次简化整体取代**（见第 4 节），本文按新架构重写。
> 名字保留——「落座」描述「从前面按进座位」比描述「从上面落进槽」还贴切。

## 1. 一句话

Mosaico 整机不拆；一颗 2×10 **直排针**永久插在它左侧的模块槽 H2 上，针尾从排针另一侧穿出来**就是触点**；
整机从前面沿屏面法向 **−Z 按进**手柄的仓里，手柄主板边缘一排**水平指向 +X 的撞针**顶在针尾端面上。

```
 手柄主板 −X 边缘                  「转接件」                          Mosaico
  撞针 →→→→→  针尾（＝触点）│ 直排针本体 │ 针头 →→→→→ 插进 H2（−X 面）
  水平指向 +X                 ←── 一根针从头到尾走直线 ──→
```

坐标系：屏幕朝使用者，原生 USB-C 朝下。+X 右、+Y 上、**+Z 从屏面指向使用者**。原点在 Mosaico 几何中心。

## 3. 三条不可违反的不变量

违反其中任何一条，就不再是方案 J。

**① Mosaico 完整。** 不拆后盖、不改主板、不焊线、不占用原生 USB-C 通路。

**② 撞针反力不经 H2 剪切，且 H2 不承受任何结构载荷。** 撞针合力沿 +X：把排针**往 H2 里压**、把 Mosaico **顶在仓的 +X 壁**上。
H2 只受沿配合轴的压力，不受剪。**这条现在靠几何天然满足**，不再需要领口、卡扣或螺钉去保证。
前框不扛撞针力，只防 +Z 脱出。

**H2 连接加固四条**（2026-09-24，用户指出官方模块「悬空挂在排针上不稳固」；官方模块的按键、传感器、本体重量全部经 20 根针进母座焊点，我们不能这样）：

1. **两端各自被壳体定死，排针只走电。** Mosaico 由仓在 X/Y/Z 三向定位；转接件（裸排针本体或穿透小板）由自己的口袋在 Y/Z 定位、在 −X 有止挡。两者之间的相对位置由壳体锁死，**排针不参与定位、不参与承力**。
2. **排针本体有托。** 排针本体（2.54 厚的塑胶条）从 Mosaico −X 面伸出的那一段，下方与两侧由壳体托住——不能像官方那样悬臂。
3. **轴向自锁。** 撞针 +X 合力把排针往母座里压，本身就是防拔出的预紧；−X 方向再由转接件口袋的止挡兜底。任何方向都拔不出来。
4. **操作力不经模块。** 10 个键在手柄主板上，按键力走主板→壳体；模块上没有任何被手指触碰的东西。这是与官方模块最本质的结构差别。

**由此得出转接件形态的倾向**：(b) 穿透小板优于 (a) 裸排针——裸排针只有 5 × 2.54 的塑胶条可供壳体抓握，穿透小板有 ~30 × 8 的板面和孔位可以入袋或加螺钉，第 1、2 条容易做实。C4 决定时计入。

**禁止**：任何在 Mosaico 本体上加胶、加卡、加螺钉的加固——违反不变量①。

**③ 供电不经软件判断。** 手柄侧无 MCU；任何芯片死机时 Mosaico 仍能正常上电。

## 5. 已算定的（Hiro／Grok 核，不同意直接推翻）

- **桥接不可能**：0.64 方针尾 ＋ Ø0.9 撞针头 → 搭接阈值 0.77 **< 半间距 1.27**。一根撞针物理上不可能同时碰两根针尾；0.77～1.77 mm 错位区是开路。
- **排布 = 乐鑫 H2 pinout，不可改。** pin17 5V_IN 挨 pin19 3V3、pin15 USB D+。整场沿行错一格即危险，需 ≥1.77 mm 错位，对导向公差 ±0.45 为 3.9 倍；排针本体被仓槽卡住后应远好于此。**进闸门。**
- **压缩量由 X 向间隙决定**（撞针区到 Mosaico −X 面），不由 Z 向压入深度决定。**X 向公差链是主链。**
- **可直连按键的 GPIO 是 11 根**（GPIO14 = EEPROM A0 专用），10 键余 1。
- **带罩排针插不进 Mosaico**（官方实物照片，左槽外壳 2×10 独立方孔、母座藏在壳后）。转接件必须是裸排针。

## 6. 当前阻断

1. **C1 直排针料号未定** → 针头长／本体厚／针尾长三个 X 向尺寸未知 → 仓槽几何无法开画。**第一块多米诺。**
2. **C2 撞针未定** → 横装方式（直角撞针？主板边立小竖板？弹片？）与耐擦触性未知。
3. **C4 EEPROM 要不要** → 决定转接件是裸排针 (a) 还是穿透小板 (b)，决定撞针装几根。
4. **U3 实物四量**未做：左槽外壳孔到母座面深度（决定针头长）；H2 两排中心 Z；Mosaico 实际宽厚；pin1 在哪端。
5. 三道机器闸门（变量／几何／错位）仍是 −Y 时代的用例，**对新架构尚未重写**（M6）。
