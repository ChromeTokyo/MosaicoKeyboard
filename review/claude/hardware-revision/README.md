# 硬件版本差异：官方文档为 V1.0，实际出货为 V1.2

- 日期：2026-09-20；整理人：Claude（主控），实际模型 `claude-opus-5`。
- 输入：用户提供的两张实拍图与一段 153 秒开箱拆机录屏（小红书「数字之心」《esp mosaico 新鲜到货》），以及用户与官方的沟通结果。
- 定位：**证据输入，不是硬件结论。** 结论须由 Chrome 判定、Hiro 复核。

## 1. 结论（最高优先级）

**官方公开的全部资料对应 BaseBoard V1.0（日期码 260710）；当前实际出货的是 BaseBoard V1.2（日期码 260821）。用户已向官方索要新版本资料，官方未提供。**

**V1.2 的背面没有 V1.0 的四个背部扩展焊盘（`SDA` / `+` / `−` / `SCL`）。**

这直接影响本项目的根本架构：**方案 A（底座经背部四触点取 I²C 与供电）在 V1.2 上不成立。**

## 2. 逐项对比

| 项 | 官方 V1.0（260710） | 实拍 V1.2（260821） | 置信度 |

## 3. 调试焊盘变化的含义

V1.2 的背面焊盘从「3V3 + UART + BOOT + EN」变为「**5V** + UART + BOOT + **RST** + 双 GND」。

- **得到**：背面直接可取 `5V` 与两个 `GND`，且 `RX`/`TX`/`BOOT`/`RST` 齐备——**不拆机即可供电并烧录**。
- **失去**：背面**没有 I²C**。本项目原设计用 I²C IO 扩展器读按键并经背部触点上行，该路径在 V1.2 背面不存在。

这两点合起来意味着：V1.2 的背面适合做「供电 + 烧录」底座，不适合做「按键输入」底座。按键输入必须另找通路。

## 4. 交互模块实物确认

录屏中清晰可见模块丝印 **`ESP-Mosaico Module-Interaction V0.2`**，与 BSP 源码中的 `MOSAICO_BOARD_TYPE_INTERACT = 0x16` 对应。板上可见：

- **两片大面积金色棋盘状焊盘＝电容触摸电极**（不是机械开关）
- 6 颗 WS2812、红外发射管、PIR、光敏电阻、四角安装孔
- 设备屏幕同时运行官方 demo：`Module-Interaction` / `LED 0–3` / `TOUCH` / `IR` / `PIR MOTION` / `LDR 59%`

**关键**：BSP 的触摸模式头文件写明该输入同时检测「手指**以及机械按键对地短路**」。官方设计本就允许在这些焊盘上接机械开关——这使「把交互模块改造成按键输入板」在电气上顺理成章。

## 5. 对现有方案的影响

| 方案 | V1.0 下的判断 | V1.2 下的判断 |
| --- | --- | --- |
| A：背部四触点取 I²C ＋ 供电 | 主选 | **不成立**（焊盘不存在） |
| A'：背部 7 焊盘取 5V ＋ GND ＋ UART ＋ BOOT ＋ RST | 未考虑 | **可行但只解决供电与烧录，不解决按键** |
| B：拆背板接 2×10P 通孔 | 备选 | 仍可能，2×10P 丝印在 V1.2 上仍在 |
| C：侧向插 H1/H2 | 已否决（盲插） | 同前 |
| D：做成官方模块 / 改造交互模块 | 新提出 | **相对权重显著上升**——它是目前唯一同时提供 I²C、GPIO 与 5V_IN 的通路 |

**建议（技术判定权仍属 Chrome）：把 A' 与 D 组合考虑**——底座经背面 7 焊盘供电与烧录，经模块槽取按键输入。两者物理位置不同，可并存。
