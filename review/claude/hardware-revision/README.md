# 硬件版本差异：官方文档为 V1.0，实际出货为 V1.2

- 日期：2026-09-20；整理人：Claude（主控），实际模型 `claude-opus-5`。
- 输入：用户提供的两张实拍图与一段 153 秒开箱拆机录屏（小红书「数字之心」《esp mosaico 新鲜到货》），以及用户与官方的沟通结果。
- 定位：**证据输入，不是硬件结论。** 结论须由 Chrome 判定、Hiro 复核。
- 修订：2026-09-20 晚，Claude 主控（实际模型 `claude-fable-5-1`）——「四焊盘取消」置信度由 confirmed 降为 derived（D-016），撤回「两张独立实拍互证」表述，补第 2.1 节与 `EVIDENCE_MANIFEST.json`（四张证据图的字节数、SHA-256 与来源）。

## 1. 结论（最高优先级）

**官方公开的全部资料对应 BaseBoard V1.0（日期码 260710）；当前实际出货的是 BaseBoard V1.2（日期码 260821）。用户已向官方索要新版本资料，官方未提供。**

**V1.2 的背面没有 V1.0 的四个背部扩展焊盘（`SDA` / `+` / `−` / `SCL`）。** 置信度 derived（2026-09-20 晚由 confirmed 降级，依据见第 2、2.1 节；实物到货目视背面后方可升为 confirmed）。

这直接影响本项目的根本架构：**方案 A（底座经背部四触点取 I²C 与供电）在 V1.2 上不成立。**

### 2.1 更强的证据（2026-09-20 晚补）

「四焊盘不存在」的主要依据不应是两张第三方实拍，而是官方 V1.2 资料本身（`references/official-v12/`，归档时间晚于本文初稿，此前未被本文引用）：

1. **官方《扩展指南 1.2.1》底板外侧全图。** `expansion_v121_zh.pdf` PDF 第 3 页（印刷页码 02）步骤 1「拆下底板上的四颗螺丝」所示为底板外侧：四角螺丝孔、两组 2×10P 通孔阵列、一排 7 个圆角矩形焊盘，**无任何四焊盘组**。7 个焊盘的位置与 `v12-assembled-back.png` 一致。
2. **官方把扩展取电改到底板内侧。** 同文 PDF 第 4 页（印刷页码 03）步骤 5 所示为底板内侧，焊盘丝印 `5V-I`／`3V3`（BTB 连接器上方）与 `GND`／`VBAT5V-O`（BTB 连接器下方），并注明「新接入硬件的双绞线，可从底板缺口处穿入」；即官方认可的取电流程是拆四颗螺丝、焊内侧焊盘、线从顶边缺口穿出（另见 `references/official-v12/README.md` 与 `exp_backplane.png`）。**若外侧仍有 I²C＋电源四焊盘，官方不会把扩展流程设计成必须拆机。**

这两条与实拍中央无焊盘叠加，使「V1.2 无背部四扩展焊盘」成为高把握的推断，但仍是推断：官方示意图无标注、无版次对照，第三方实拍不能覆盖整板。故置信度为 derived；实物到货后按测量手册第 0 节读版本并目视背面，方可改为 confirmed。

另三条从实拍得到的观察（均为 derived，须实物确认）：

- **2×10P 通孔已被焊锡填满。** `v12-baseboard-back.png` 中两组通孔呈实心银色，非空孔。若属实，方案 B「对背面通孔做垂直 Pogo 接触」面对的接触面形态与官方 V1.0 图不同。
- **四角银色金属块嵌在外壳里，不在 PCB 上。** 同图四角的银色块位于白色外壳角部凹槽内，PCB 四角只有螺丝孔。其性质（磁铁或结构件）仍未证实。
- **BaseBoard 本身就是整机后盖板。** 官方扩展指南步骤 1、2 与实拍一致：拆四颗螺丝即可把 BaseBoard 整块取下，其外侧贴标签面就是整机背面。本文第 2 节初稿把「整机背盖」与「BaseBoard 背面」当作两个独立对象的表述不准确，已随上表更正。

## 3. 调试焊盘变化的含义

V1.2 的背面焊盘从「3V3 + UART + BOOT + EN」变为「**5V** + UART + BOOT + **RST** + 双 GND」。

- **得到**：背面直接可取 `5V` 与两个 `GND`，且 `RX`/`TX`/`BOOT`/`RST` 齐备——**不拆机即可供电并烧录**。
- **失去**：背面**没有 I²C**。本项目原设计用 I²C IO 扩展器读按键并经背部触点上行，该路径在 V1.2 背面不存在。

这两点合起来意味着：V1.2 的背面适合做「供电 + 烧录」底座，不适合做「按键输入」底座。按键输入必须另找通路。

## 4. 交互模块实物确认

录屏中清晰可见模块丝印 **`ESP-Mosaico Module-Interaction V0.2`**，与 BSP 源码中的 `MOSAICO_BOARD_TYPE_INTERACT = 0x16` 对应。板上可见：

- **两片大面积金色棋盘状焊盘＝电容触摸电极**（不是机械开关）
- 6 颗 WS2812、红外发射管、PIR、光敏电阻、四角安装孔
- 设备屏幕同时运行官方 demo：`Module-Interaction` / `LED 0–3` / `TOUCH` / `IR` / `PIR MOTION` / `LDR 59%`

**关键**：BSP 的触摸模式头文件写明该输入同时检测「手指**以及机械按键对地短路**」。官方设计本就允许在这些焊盘上接机械开关——这使「把交互模块改造成按键输入板」在电气上顺理成章。

## 5. 对现有方案的影响

| 方案 | V1.0 下的判断 | V1.2 下的判断 |
| --- | --- | --- |
| A：背部四触点取 I²C ＋ 供电 | 主选 | **不成立**（焊盘不存在） |
| A'：背部 7 焊盘取 5V ＋ GND ＋ UART ＋ BOOT ＋ RST | 未考虑 | **可行但只解决供电与烧录，不解决按键** |
| B：拆背板接 2×10P 通孔 | 备选 | 仍可能，2×10P 丝印在 V1.2 上仍在 |
| C：侧向插 H1/H2 | 已否决（盲插） | 同前 |
| D：做成官方模块 / 改造交互模块 | 新提出 | **相对权重显著上升**——它是目前唯一同时提供 I²C、GPIO 与 5V_IN 的通路 |

**建议（技术判定权仍属 Chrome）：把 A' 与 D 组合考虑**——底座经背面 7 焊盘供电与烧录，经模块槽取按键输入。两者物理位置不同，可并存。

## 7. 本文的局限

- 实拍图与录屏均来自第三方开箱内容，非用户本人的实物；用户的机器尚未到货，实际版本待到货确认。
- 「四焊盘不存在」是对两张照片与官方示意图叠加的推断（derived，见第 2.1 节），不能排除焊盘被移到本文未观察到的位置。**到货后必须实物确认。**
- 45.27 mm 为视频画面读数，被测部位、是否含模块、卡尺是否归零均未知，**不得作为工程尺寸**。
- 四角银色块判为磁铁属形态推断，未证实。
- 153 秒录屏不在仓库、无 URL；两张 JPG 为录屏抽帧（JFIF 注释 `Lavc62.28.100`）。录屏中的观察（版本丝印、45.27 mm 读数、交互模块细节）目前不可复核，来源信息以 `EVIDENCE_MANIFEST.json` 为准。
- 实拍丝印「V1.2」与官方扩展指南所称「仅适用于 1.2.1 版本及以上」是否同一版次无法判定：丝印为 BaseBoard 的版本号与日期码，eFuse 中的 variant 在 CoreBoard 芯片内，两者与文档版本号的对应关系官方未说明。
