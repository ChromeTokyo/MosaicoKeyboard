>
> **因此到货后先做第 0 步确认版本，再决定走第 4A（V1.0）还是第 4B（V1.2）。** 第 1、2、3、5 步两版通用。若实物板号与两版都不符，仍可记录外形与照片，电气对应暂停（沿用 Chrome v0.1 原则）。

**到货当天先认版，再做第 1～5 步中适用的项目。** 用已有卡尺、手机和下表的少量附件即可开始；第 6 步拆背板可中止，第 7 步电气复验须满足专门条件。你只需量、拍、记录，触点坐标换算和误差评估由 Chrome 完成，Hiro 复核后才能冻结。

## 0. 先确认版本（约 5 分钟，**在任何测量之前做**）

不开机、不通电，只看和拍。

用户提供的开箱视频显示 **Baseboard-A V1.2／Coreboard V1.2**，背部没有看到官方 Fig.7 V1.0 的中央四圆焊盘；边缘调试焊盘形状、数量也不同。见 [带时间点的对照证据](../review/chrome/T14/video-20260920/README.md)（Chrome，PR #12）。因此不要为满足本手册去寻找、刮开或接触一个实物上不存在的“四触点”。

1. 翻到背面，找**整机背盖**上的丝印与图案。拍 `P00a_背盖全景`。
   - 若背盖中央是**四个金色圆焊盘**，多半是 V1.0。
   - 若背盖中央是**二维码**、没有四个圆焊盘，多半是 V1.2。
2. 数**背面底部一排焊盘的个数并抄下每个的丝印**，拍 `P00b_调试焊盘`（要能看清每个字）。
   - **6 个**且为 `3V3 TX RX BOOT EN GND` → V1.0
   - **7 个**且为 `GND BOOT RST RX TX 5V GND` → V1.2
3. 若背盖可见板号丝印，抄下**完整字符串**（形如 `ESP-Mosaico Baseboard-A` ＋ 六位日期码 ＋ `V1.x`），拍 `P00c_板号`。日期码 `260710`＝V1.0、`260821`＝V1.2。**照抄实物，不要按本文预期填。** CoreBoard 与 BaseBoard 版本分别记录；看不见的写“不可见”，**不为找版本拆屏幕或拆电路板**（Chrome，PR #12）。
4. 拍板子**四角**特写 `P00d_四角`：记录是沉金安装孔，还是嵌了银色金属块（疑似磁铁，未证实）。
5. 拍**左右两侧**特写 `P00e_左侧`、`P00f_右侧`：模块接口是排针排母，还是一排弹簧针／触点。**不要插拔模块。**
6. 拍完整正背面与两侧接口的原状照片。“揭外层薄片”和“卸下 BaseBoard”分开记录；视频不能保证你的机器同样可拆，**第一轮不揭、不松螺丝，先交原状照片**。侧面可拆插接作为候选方向，等待版本和 pinout 核对（Chrome，PR #12）。

| 判定 | 走哪一节 |
| --- | --- |
| 确认 V1.0（背面清楚可见四圆焊盘且标着 SDA／+／−／SCL） | 第 4A 节（Chrome 原规程）。先按第 2 节拍全景和方向，Chrome 核对与官方图一致后再做第 4A 节；电气复验仍须满足第 7 节前提（Chrome，PR #12） |
| 确认 V1.2（布局像视频，只有另一排调试点） | **第 4B 节**。第 4A 节及第 7 节填“不适用／待确认”；**不要把边缘调试排选四个点代替 P1～P4，也不尝试供电探认**（Chrome，PR #12） |
| 被薄片／外盖挡住不能判断、两者都对不上，或证据矛盾 | **停在这里**：先做外壳、接口照片和可安全测的外形（第 1、2、3 节），把 `P00a–P00f` 交回，等 Chrome 判定后再继续。不要自行推断 |

无论哪一版，第 1、2、3、5 节都照做。

## 1. 桌面准备与器材

在明亮、干燥、无杂物的桌面铺绝缘软垫。先将设备正常关机，拔掉所有 USB、充电器；**已插在槽里的模块保持原位并拍照，不为测量插拔；未插的模块单独拍。** 不按 BOOT，也不接新底座。**关机不代表内置电池断开：金属尺、卡尺、螺丝刀和表笔不要同时碰到两个触点。** 不拆屏幕、不拔不认识的连接器、不撬电池、不刮焊锡、不做短路或额定电流试验。发现鼓包、异味、发热或破损，停止测量并记录现象。

### 到货测量需要什么

这里的精度是本规程的选购／数据质量要求，不是对你已有仪器性能的认定；先拍型号与说明书规格，不必重复购买。

| 器材 | 要求／用途 | 是否现在补购 |
| --- | --- | --- |
| 已有卡尺 | 建议量程至少 100 mm、分辨率 0.01 mm、说明书最大允许误差不大于 ±0.03 mm；记录真实规格。只量外壳和标尺，勿跨碰焊盘 | 已有，先核规格；达不到也可做粗测并注明 |
| 已有万用表 | 直流电压分辨率 ≤1 mV（低量程）、精度 ≤±(0.5%读数+3字)；低阻分辨率 ≤0.1 Ω。使用说明书可查 | 已有；本轮外形测量不需要通电使用 |
| 手机／相机、固定俯拍支架、漫射灯 | 能对焦近物；整个约 10 mm 触点排横跨照片至少 600 像素，优选 1000 像素；每盘直径至少 100 像素。用后置普通镜头，不用超广角／人像模式 | 支架建议补；先试手机，达不到再考虑微距镜头／显微镜 |
| 带刻线的短标尺，两方向均可读 | 小于等于 0.5 mm 分度，用已有卡尺核查一段约 20 mm 的实际长度；标尺放在绝缘支架上。普通尺仅用于初测，不能据此声称 0.01 mm 精度 | 建议补；可用清晰打印十字标靶，但必须实测横纵长度，禁止相信打印缩放 |
| 非金属托架、白纸、低黏纸胶带、螺丝小盒 | 固定设备／标尺、方向标签、保留拆装顺序；胶带只贴外壳，不贴屏幕、焊盘、散热材料 | 家用材料可代替，无精度要求 |
| 匹配螺丝头的精密手动螺丝刀 | 先看实物头型，选能完全贴合的批头；不要预购假定螺丝规格，不用电动工具 | 做拆背板检查前准备 |
| 放大镜或手机微距 | 能分辨通孔是空洞、环形铜面还是焊锡突起；不能只看像素标称值 | 手机已满足则无需买 |
| 绝缘细表笔／微型夹具 | 导电露出长度尽可能短（目标 ≤1 mm），夹具不碰相邻焊盘；仅第 7 步条件齐备后使用 | 电气复验前准备，当前不接触电路 |

若照片无法支持触点中心 ±0.10 mm 以内的**估计测量误差**，Chrome 将安排局部补拍／测量显微镜验证。可选后备器材：有固定支架、可保存原图的显微镜，配分度 0.01 mm、10 mm 标距误差 ≤±0.01 mm 且有规格证明的刻线标定片。显微镜倍率标签本身不能代替标定。不必在第一轮照片之前买显微镜。

## 2. 建档、定方向（约 10 分钟）

1. 建立文件夹 `T14_到货日期_样机01`。复制 [记录表](../review/chrome/T14/MEASUREMENT_RECORD.md)，不会编辑 Markdown 就按同样字段写在纸上，拍照交回也可以。所有长度用 **mm**，未知写“未测”，不要填 0。
2. 拍包装型号、外壳版本／板号。原始照片自己留存；公开仓库只放去除序列号、二维码等私人标识的副本，并注明裁剪／遮挡。不要把原图覆盖掉。
3. 屏幕朝你，将设备摆正，拍 `P01_正面`；选定此时的上边，在**外壳边缘**贴小纸签“T↑”。纸签在全部照片保留，后续不因看背面重新定义“上”。如果屏幕朝向不明确，以你选定的物理边为准并拍摄连接器位置，Chrome 再与官方图对齐。
4. 像翻书那样绕竖直轴翻到背面，保持“T↑”仍朝上。拍 `P02_背面全景`。仅在确有对应四圆焊盘时，按左→右记作 P1、P2、P3、P4，先照抄实物丝印；没有则记录实际布局，**不要凭本文把照片旋转到预期结果**。
5. 拍 `P03_上边`、`P04_右边`、`P05_下边`、`P06_左边`、`P07_侧斜视`，每张放方向纸签。六视图上的“左右”以该照片面朝你为准，不自行做镜像。

官方 Fig.7 背面外视顺序为 **SDA／+／−／SCL**；与其相对的底座顶视是 **SCL／−／+／SDA**。实物方向和标签一旦与图不一致，记录差异，不试着给它供电。具体坐标变换见 [统一接口文件](INTERFACE_CONTROL.md)。

## 3. 卡尺量外形（约 20 分钟）

先擦净量爪，闭合查零；张开、闭合重复 3 次并拍 `P08_卡尺零位`。每一项轻轻接触、读数、完全松开后重新摆放，量 **3 次**，三次原始数都保留，不删掉“不像预期”的读数。记录测量部位并拍一张能同时看见接触位置和显示值的照片。

| 编号 | 测什么 | 卡尺怎么放／照片 |
| --- | --- | --- |
| M01、M02 | 主体左右宽 W、上下高 H | 正面视角；分别夹住外壳两侧、上下边，不夹按钮或接口。记录是否含突出部，`P09/P10` |
| M03 | 主体总厚 T | 只轻触能确认是绝缘外壳的前后边框，不夹屏幕玻璃；若背面为裸 PCB、金属或只能碰到元件，不夹测厚度。另拍带尺侧视，`P11` |
| M04 | 最大外包络 | 单独记录按钮、连接器等突出部分导致的最大宽／高／厚；勿压下按钮获得较小尺寸，`P12` |
| M05 | 背板支承面与触点面的相对高度 | 将设备屏幕侧放在四个软支点上，屏幕悬空、不受压；拍触点齐平／凹入／凸出的近侧视。无绝缘深度夹具时只记外观，不让卡尺深度杆探入焊盘，`P13` |
| M06 | 外部开孔位置和大小 | USB-C、扬声器、麦克风、AI Key、BOOT、开关、充电灯逐一拍近照；在旁边放标尺，记录距同一外壳边缘的距离。小孔不塞量爪，`P14_名称` |
| M07 | USB 插头操作空间 | 先拍设备拔线状态；拿日常插头在旁边比对其塑壳尺寸、线弯曲占用，USB 另一端不连电源。不施力碰电路；记录插拔要从哪个方向伸手，`P15` |
| M08 | 四角螺丝／结构支承 | 拍头型、孔位置、支承凸台。头径可非接触拍照；螺丝型号、扭矩、孔深先留空，不凭照片选螺丝，`P16` |

普通外形三次最大值减最小值 >0.10 mm 时再量一组，保留两组；仍不一致就写“重复性不足”。这个数是补测触发值，不是成品公差。卡尺小数位多不表示结果精度高，接触软壳、曲面和薄屏幕时尤需注明限制。

## 4A. 四触点：拍清楚、放对比例尺（**仅 V1.0**，且仅适用于已认版、确有四触点的样机；核心步骤，约 20 分钟）

**这一轮用卡尺标定照片的参照，不用金属卡尺量两个通电状态未知的焊盘。** 平面圆形焊盘没有可夹持的侧壁；不可靠的直接读数也不能冻结接口。你只负责留下真实尺寸参照和原图，Chrome 从实物照片提取几何，并判断是否还需显微测量／绝缘测量夹具。

1. 设备固定，背面朝上，“T↑”向上，四个焊盘居中。用非金属托架支撑外壳，勿压屏幕和按钮。
2. 准备一个有横／纵刻线的标靶或两条短标尺。先拿离设备远一点，用卡尺量两个刻线之间约 20 mm 的距离，横、纵各量 3 次，记为 **RX、RY**。方法：标靶平放，两爪的同一测量边从正上方分别对准两根刻线的同侧边缘（如都对左边缘），不要一端取线中心另一端取外边缘；不靠挤压纸张读数。照片同时拍清两端对齐位置与显示，必要时增加两端微距；线太粗、量爪遮挡或无法对齐就记“粗测标靶”，后续换有规格的标定片。标明用的是哪两根刻线；打印图必须实测，不能默认每格 1 mm。
3. 将刻线参照放在四触点旁边，使用绝缘垫片使**刻线所在平面与焊盘表面齐平**，不是把尺放在更低的桌面，也不是叠在焊盘上。不能碰电路或遮住焊盘。拍 `P17_比例尺侧视` 证明高度关系；不能确认齐平时注明“高度差未知”，这组仅供初测。
4. 相机镜头放在触点正上方，保持与背面垂直。用固定支架、均匀侧光，关闭美颜／景深虚化／数码变焦。画面保留焊盘、两方向参照、T↑ 和外壳轮廓；光学变焦允许，但参照必须同时入镜。
5. 拍 `P18_触点与外壳全景`，用于关联触点与定位边；再拍 `P19_四触点微距`，用于测间距与直径。不要仅交一张脱离外壳的裁切图。
6. 完全移开相机、重新放正，拍第 2、3 组 `P20/P21`；设备方向不变。再让标靶方向交换或在焊盘另一侧重放后拍第 4 组 `P22`，用于发现畸变／高度差。每次移动后检查同平面。
7. 在相册放大检查：每个圆盘边界、丝印、参考刻线都清楚，无反光淹没边界；四盘排至少 600 像素、优选 1000 像素，圆盘至少 100 像素。达不到就调整光线／距离，或将微距设备列为补测条件。保留相机原文件，不经聊天软件压缩，不裁掉参照。

**记录的目标量：** P1～P4 各自中心 `(x,y)`、三个相邻间距 `p12/p23/p34`、首尾中心距 `L14`、每个圆盘的横纵直径 `d1…d4`、触点排到外壳两条基准边的照片投影偏移。如果外壳边与焊盘不共面或高度差未知，投影偏移不能直接作为制造坐标；另留侧视与各平面的独立参照，由 Chrome 建立三维基准后换算。你可以留空中心值，Chrome 负责回填测量方法、计算和误差。不得先把三个间距都写成同一个“标准值”。

Chrome 处理规则：横纵分别标定；用多图核对畸变和重复性；对圆盘左右边缘取中点，不凭丝印位置选中心；记录像素原始点与参照实长。验证 `L14 ≈ p12+p23+p34`。D-009-R 的约 2.516 mm（名义 2.54 mm 候选）只作待验证线索，绝不拉伸照片去迎合它。坐标估计误差目标 ≤±0.10 mm；多组差 >0.10 mm、标尺高度未知或边缘不清即要求补测，**不能把“没有超差”直接当精度已经证明**。卡尺规格、刻线宽度、标靶变形、像素选择和透视残差均需计入误差。

## 4B. V1.2 背面：七焊盘与模块接口（**仅 V1.2**，约 25 分钟）

视频所见 V1.2 背面没有四触点，原设计「经背部四触点取 I²C 与供电」不能套用到该版。本节记录到货实物实际暴露了什么。**全程不通电、不插拔模块、不拆任何螺丝。**

### 4B.1 七个背面焊盘

1. 先在**远离设备**的位置用卡尺量标尺约 20 mm 的两条刻线间距，横、纵各重新摆放量 3 次；记 `QRX`、`QRY` 的原始读数及选用的刻线。标尺/标靶放在绝缘支架上，不压焊盘、不让金属尺跨碰触点。俯拍整排焊盘 `Q01_七焊盘全景`：整排横跨照片至少 600 像素，优选 1000；两方向参照尽量与焊盘**同一平面**且同镜入画，再拍低角度 `Q01a_标尺高度` 说明是否齐平。做不到齐平就写“高度未知”，照片只供初测，不能冻结坐标。
2. 逐个抄下丝印，按**照片中从左到右**记作 Q1…Q7，连同丝印一起填进记录表。**照抄实物，不要按本文预期排序。** 参考（可能不符，以实物为准）：`GND` `BOOT` `RST` `RX` `TX` `5V` `GND`。
3. 拍一张能同时看到**整排焊盘与板号丝印**的照片 `Q02_焊盘与板号`，用于确认两者属于同一块板。
4. 用放大镜或手机微距拍 `Q03_焊盘表面`：判断焊盘是平面镀金、有焊锡凸起，还是带孔。这决定底座能用平头弹簧针还是需要别的接触方式。
5. 卡尺**只量绝缘外壳**，不要跨碰焊盘：在 `Q01` 带比例尺照片上标出焊盘排相对最近外壳边的大致位置（`M0B1`）和整排大致总长（`M0B2`）。如果焊盘与标尺高度不同或看不清，写“不能估算”，只保留原图。**这是外观定位线索，不是制造坐标或卡尺读数。**

### 4B.2 中央区域

6. 俯拍背盖中央 `Q04_背盖中央`：记录中央到底是什么（二维码／丝印／其他），**确认有没有任何形式的四触点或其残留窗口**。这是本节最关键的一张照片——它决定方案 A 是否真的不成立。
7. 若背盖中央有任何凹槽、窗口、堵孔或与周围不同的区域，单独拍 `Q05_中央异常` 并描述。

### 4B.3 四角与模块接口

8. 四角特写 `Q06_四角`：银色金属块的形状、是否与外壳齐平、有无极性标记。**不要用磁铁去试吸**，也不要拿铁器靠近——本项目不需要靠这个判断，Chrome 会从其他证据判定。
9. 左右两侧模块接口特写 `Q07_左侧接口`、`Q08_右侧接口`：每侧拍**正对开口、低角度侧视、带 T↑／邻近外壳边和 USB-C 的全景**各一张，三图分别加 `_正视`、`_斜视`、`_定位` 后缀。数可见孔位的行、列，抄 pin 1／缺口／键位标记，记 10 针沿机身高还是厚方向排列、插入轴朝哪边。把已量横纵刻线的短标尺放在接口旁的绝缘支架上，拍侧视说明**刻线与可见孔口是否齐平**；不齐平或被已装模块遮挡就写“不能定尺寸”，保留外壳全景。**不把标尺、卡尺深度杆、表笔或塑料探针插入仍接内电池的接口。**
10. 在 `Q07` 照片上标出左槽可见首尾孔中心、相邻三组孔中心、两排中心和开口边，标出与同图上下外壳边／USB-C 的对应关系；Chrome 从原图回算行列方向、间距、首尾跨距和槽口相对外壳的位置。用卡尺量**安全可触的外壳外表面**三次并写清是哪两面；孔位中心、槽口内凹深若无同平面参照和无接触夹具，填“未测”，后续另出检具步骤。照片中的像素距离不可冒充卡尺实测或装配公差。
11. 若随机附带了模块（交互模块、摄像头模块），**未插的模块单独拍；已插的保持原位，只拍可见面**，不要为拍齐而插拔：`Q09_模块正面`、`Q10_模块背面`、`Q11_模块连接边特写`，并抄可见的型号、版本、日期码；被挡住的一面填“不适用／原装占槽”。

### 4B.4 不要做的事

- 不要把表笔、卡尺、镊子同时搭在两个焊盘上。**关机不代表内置电池断开。**
- 不要插拔模块或用力对位——插拔痕迹会影响后续对连接方式的判断。
- 不要撕背盖标签、不要拧螺丝。拆背板属于第 6 节，且在 V1.2 上**暂缓**，等 Chrome 依据本节照片给出判断后再定。
- 不要根据本文的「参考丝印」去修正你看到的实物。**实物与本文不一致时，以实物为准并如实记录。**

## 5. 第一轮交回材料

两版都交 `P00a–P00f`（认版）、`P01–P16` 中实际适用的原状/外形照片、三次卡尺原数、卡尺／万用表型号及规格、[记录表](../review/chrome/T14/MEASUREMENT_RECORD.md)。**V1.0 且确认四圆焊盘**再交 `P17–P22`、`RX/RY` 和 P1–P4 丝印；**V1.2**则交 `Q01、Q01a、Q02–Q11` 中实际适用的照片、`QRX/QRY` 标尺原数、Q1–Q7 丝印、`M0B1/M0B2` 粗略位置、`Q07/Q08` 的三视图与左槽可见孔位/外壳基准标注。没有随箱模块时 `Q09–Q11` 填“不适用／未附模块”；原装占槽时被遮挡项填“不适用／原装占槽”。缺哪张就注明原因；不要为了补齐而危险操作。照片过大可分批交，原图自己留存。无需等拆机或通断测完才交第一轮。

完成判据是“照片方向可辨、参照可追溯、测量原数保留、缺项写明”，不是“尺寸符合 A0”。Chrome 将据此给出数据完整性检查和下一批缺项；Hiro 复核导出的尺寸链。T14 的**规程交付**和**用户实测完成**分别登记。

## 6. 旧 V1.0 方案 B：背板能否无损拆装（第二轮，可中止；V1.2 暂不执行）

**V1.2 第一轮只做第 0～5 节；本节不适用，不自行揭背面薄片或拆螺丝。** 本仓官方 1.2.1+ 扩展指南的拆底板示意还涉及电池和喇叭，不能作为本机自行拆装授权。下面是旧 V1.0 四触点方案 B 的留档步骤，仅在 Chrome 根据同版实物照片确认独立外盖并给出标注后使用。新增视频表明，背面外层薄片与 BaseBoard 电路板是两层不同对象，不能统一称为“背板”后照同一拆法执行。若螺丝固定的是电路板，或拆开会分离板间连接器，到拍照为止。官方 Fig.7 是 BaseBoard 背面，不证明另有可直接取下的后盖；`MOSAICO.3mf` 的来源见 [PR #10 的二次更正](../review/claude/3mf-analysis.md)，也不能证明到货构造。**看到螺丝不等于可安全拆下。** 先交 B01 全景与螺丝近照；若不愿拆或批头不合适，记录“未拆”，不影响第一轮材料交回。

1. 核对已收到与本机一致的“外盖／螺丝标注图”；没有就只拍 `B01_四角螺丝原状`，不松螺丝。条件齐备后，设备关机、全部拔线，按第 1 步摆放。每颗螺丝编号 S1～S4；手动逐颗松开，单独收好并记原位置。转不动、滑牙、有封签／胶粘立即停，禁止加热或强撬。型号和扭矩未知，不能规定统一拧紧力。
2. 螺丝去除后，只尝试从外壳边缘轻轻抬起背板；如果有阻力、导线、导热垫粘连或被别的连接器挂住，停在原位拍照，装回可恢复的部分。不要把“背板可拆”当成拉断排线的许可。
3. 若能自然取下，背板内面单独放好；拍 `B02_背板内面`、`B03_整片背面` 和四个斜视。不要碰内部电池／PCB，不继续拆 CoreBoard 或屏幕。
4. 对左右各 2×10 孔逐一拍 `B04_左接口`、`B05_右接口` 的垂直与低角度近照，并带同平面参照；检查**空孔／焊锡填满／焊脚突起／连接器遮挡**。不把针插入孔，不用刀刮，禁止为了露铜拆焊连接器。
5. 拍 `B06_调试点`（逐个抄实物丝印及数量）、`B07_背板支承与散热接触`。逐项记录裸露电池、导线、导热垫、金属屏蔽、螺柱是否随背板失去固定。侧插口占用背面投影也要拍。
6. 原样装回：材料位置不变，螺丝回原孔，手动轻拧至贴合即停，不追加大力。检查壳缝、按钮、USB 插拔是否回到拆前状态。先只做一次拆装；一次可复原后才可再做两次，逐次记录。出现咬牙、松动、划伤、垫片移位即停止，不追求次数。
7. **本规程不安排背板拆下时通电。** 散热变化与结构耐久仍需 Chrome 设计专门对照夹具与工况，在 G6／H3 复核路径中验证；三次轻装拆只能作为重复可拆的初步证据。

B 方案的“可用”至少还要证明：针头落在受控导电面而非掉进孔、孔环／锡面允许接触且可清洁、接触面高度可重复、针力不使 PCB 弯曲、背板替代支承／散热路径存在、原功能保留。照片能筛掉明显不可行方案，不能证明接触寿命和载流。

## 7. 旧 V1.0 四触点万用表复验：条件未齐时明确留待办（V1.2 第一轮不适用）

D-008 要求实物通断复验，本项不会因拍到了丝印而自动通过。**当前不让你在仍接内置电池的设备上用蜂鸣／电阻档探针。** 开关 OFF、屏幕黑和电量 0% 均不是断电证明。不要把电流档跨接“+”和“−”，不要把 USB 金属外壳先当作信号 GND。

要执行这项，Chrome 必须先提供：与你板号匹配的实物标注照片；明确的电池安全断开方式或能隔离出的无源 BaseBoard；经审核的表笔夹具；准确的测试点配对表及判据。若电池不可安全无损断开，不自行拆焊，这项转交具备条件的实测人员，方案冻结继续等待。

届时规程要包含：所有外部供电拔除 → 按已确认方法隔离内置电池 → 电压档确认目标点对无残余电压 → 表笔短接记录线阻 → 在断电无源路径测数值并拍照 → 互换表笔核对 → 恢复原装。配对至少覆盖 SDA→已确认的 GPIO0 网络、SCL→GPIO1 网络、−→已确认 GND、+→**待证实的 BaseBoard 电源路径**，并检查各触点对 3V3 是否有直接低阻短接。主控建议的“3V3 对四点不导通”只能用来筛查误接，不能把电阻无穷大作为统一判据：SDA/SCL 到 MCU_3V3 本来有 4.7 kΩ 上拉，其他半导体也可能产生双向不同读数。不能根据相似外形猜针脚，不将有蜂鸣等同于直接铜连；半导体／保护器件路径需按原理图解释。

**阻塞项及关闭方式：** 缺实物板号、BaseBoard 转接网络证据和电池隔离可操作照片。本项标“未执行”，由 Chrome 补现场配对图与步骤后、Hiro 复核可执行性；不会要求你现在摸索拆电池。T14 第一轮收集材料可独立完成，G1 不能因此提前通过。
