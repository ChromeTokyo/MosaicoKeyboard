## 0. 现行架构一段话（方案 J，落座式，09-24 版）

```
 手柄主板 −X 边缘                「转接件」                          Mosaico
  撞针 →→→→→  针尾（＝触点）│ 直排针本体 │ 针头 →→→→→ 插进 H2（−X 面，永久不拔）
  水平指向 +X                ←── 一根针从头到尾走直线 ──→
```

- **直排针**（2×10、2.54、裸、无罩）：针头插 H2，针尾从本体另一侧穿出，**针尾端面就是触点**。
- **撞针**装在手柄主板 −X 边缘，**针轴沿 +X 水平**，顶在针尾端面上。
- **整机沿 −Z 压入**（从前面按进仓）；下压时针尾**擦过**撞针头，坐底后撞针沿 X 压缩。
- **力路径**：撞针合力沿 +X → 把排针往 H2 里压 → Mosaico 顶在仓 +X 壁。**H2 只受压不受剪。**
  前框不扛撞针力，只防 +Z 脱出（横压摩擦已给 ~3 N，加一道浅唇）。
- **排布 = 乐鑫 H2 pinout，不可改。** 底座侧不需要的位置（pin18 5V_OUT、pin13/15 USB、pin10 EEPROM A0）不装撞针。
- **电源用现成模块**；底座**无 MCU**；按键组中心在机身中线 **Y = −19.5**。
- 三条不变量：① Mosaico 完整不拆不改；② 撞针反力不经 H2 剪切（现在靠几何天然满足）；③ 供电不经软件判断。

决策记录：`docs/DECISIONS.md` D-028（架构）、D-029（能买就不设计）、D-030（按键下移）。

## 3. 转向前后必须知道的硬发现

0. **官方刚发了同类设计**：MakerWorld `@ESP_MOSAICO` 09-24 发布「Module Interaction」——官方 PCB ＋ 2×10 排针直插侧槽 ＋ 两个机械键盘轴。**架构被官方印证**；模块外形 44.90 × 44.90 × 10.90；朝 Mosaico 一侧壳体敞开无壁。解析与来源 SHA 见 `references/official-module-interaction/ANALYSIS.md`。其 §3.2 提出一条「手柄主板放 2×10 母座、模块像级联一样插进来」的更省路线，**与撞针方案二选一，待用户定**。

1. **带罩排针插不进 Mosaico。** `references/official-v12/assembly_en.pdf` 第 1 页官方实物照片放大：左槽外壳是 **2×10 个独立方孔**，母座藏在壳后，没有能容纳罩体的窗口。C9144（PR #51/#54 比过的带罩弯简牛）**出局**；Chrome #54 的两个裸右角候选也出局（要**直**的）。**C1 必须是裸直排针。**
2. **针头长要吃掉外壳凹深。** 外壳孔到母座面若 >2 mm，标准 6 mm 针头插深 <4 mm，H2 接触不可靠——C1 可能要选长针版。U3① 到货一量就知道。
3. **H2 中心位置估值**：Z 由官方照片像素估 ≈ 0 ±0.5；Y 由官方 3mf 的 ±X 面浅凹台中心 y=−0.014 间接推 ≈ 0。**均为 derived，U3② 实测前不冻结。**
4. **桥接不可能**：0.64 方针尾 ＋ Ø0.9 撞针头 → 搭接阈值 0.77 **< 半间距 1.27**。上周花两轮工作流证明的一针压两铜机理在此不存在。`check_j2_mismate.py` 改这两个几何数即可复用。
5. **排布固定带来的唯一危险**：pin17 5V_IN 挨 pin19 3V3、pin15 USB D+。整场沿行错一格（2.54）即危险，需 ≥1.77 mm 错位，对 ±0.45 导向公差 3.9 倍；排针本体被仓槽卡住后应远好于此。**进 C3 的枚举。**
6. **电源模块两条会咬人的判据**：**无轻载自动关机**（IP5306 类 <50 mA 约 30 s 自断电，Mosaico 深睡可能触发）；**支持边充边放**。另五条：带 NTC、5 V 精度/纹波、1S 保护齐全、可返修、有现货。
7. **撞针压缩量由 X 向间隙决定，不由 Z 向压入深度决定。** X 向公差链是主链（M5）。

## 4. 依赖与顺序

```
C1 排针料号 ──┬──→ M1 仓槽几何 ──→ M3 板外形 DXF ──┐
C2 撞针料号 ──┘         ↑                          ├──→ C6 手柄主板 ──→ 打样
C4 EEPROM/形态 ────────→ C3 撞针脚位 ───────────────┤
C5 电源模块 ──→ 电池仓尺寸 ──→ M2 按键下移干涉重算 ──┘
M4 Z 叠层、M5 公差链、M6 闸门、M7 文档：与上面并行，M6 在 M1 之后收口
```

**C1 是第一块多米诺。** C4、C5 独立，越早越好。

## 5. 只能用户定的

1. **Mosaico 在 Y 向跟不跟按键一起下移**（按键到中线 −19.5，Mosaico 现在中心 0）。
2. **转接件 (a) 裸排针 还是 (b) 穿透小板**——C4 给出技术结论后，若两者都可行，选简单还是选保护（EEPROM＋串阻＋针尾防碰弯）。
3. **撞针总数**：5V 用一针还是两针（H2 只一根 5V_IN，两撞针只能在底座侧并联）；SDA/SCL/3V3 装不装。
4. **前框形态**：既然不扛力，做成薄边框、还是干脆无框只留浅唇。
