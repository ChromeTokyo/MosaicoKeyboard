## 2. 我已经算过并认定的（你核，不同意直接推翻）

**桥接机理消失。** 上周 P2 方案死在「焊盘 Ø2.0 ＋ 针尖 Ø0.9 → 搭接阈值 1.45 > 半间距 1.27，一针压两铜」。
