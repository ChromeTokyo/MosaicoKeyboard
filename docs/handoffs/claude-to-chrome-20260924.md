## 1. 新前提（用户 09-24 图确认）：直排针穿透，针尾即触点，撞针横着顶

用户原话：「直接把排针直线转接成触点，然后排针横置……这样放肯定不会伤到 Mosaico 的接口。」
用户标注图 ＋ 我提的两选一，**用户确认的是「直排针，撞针横着顶针尾」**，不是右角排针针脚朝下。

```
 手柄主板边缘                   「转接板」                        Mosaico
  撞针 →→→→  针尾（＝触点）│ 排针本体（2.54 厚）│ 针头 →→→→ 插进 H2
  水平指向 +X               ←── 一根针从头到尾走直线 ──→          −X 面
```

- **排针是直的**，针头插 H2（+X 方向），针尾从本体另一侧穿出（−X 方向），**针尾就是触点**。
- **撞针装在手柄主板的边缘，水平指向 +X**，顶在针尾端面上。
- **整机沿 −Z 压入**（用户 09-23 定的方向不变）：下压时针尾**滑过**撞针头——相机电池仓那种擦触；
  坐到底后撞针沿 X 压缩，**压缩量由仓的 X 向宽度决定，不由 Z 向压入深度决定**。
- **力路径**：撞针 12 N 沿 +X 推排针 → 把针头**往 H2 里压** → Mosaico 被顶在仓的 +X 壁上。
  **H2 只受沿配合轴的压力，不受剪力**；前框不必扛撞针力，只需防 +Z 脱出（12 N × μ≈0.3 的摩擦已给 ~3.6 N，再加一道浅唇即可）。
  **屏边 2 mm 边框扛 12 N 的难题消失。**
- 「转接板」两种落地：**(a) 就是排针本体**，无板；**(b) 一条 ~30×8 mm 的穿透小板**，排针焊穿它，针尾从板背穿出——
  几乎零成本，但能放回 EEPROM 与按键串阻、给底座槽口一个好卡的边。**你选。**

## 2. 我已经算过并认定的（你核，不同意直接推翻）
