## 2. 我已经算过并认定的（你核，不同意直接推翻）

**桥接机理消失。** 上周 P2 方案死在「焊盘 Ø2.0 ＋ 针尖 Ø0.9 → 搭接阈值 1.45 > 半间距 1.27，一针压两铜」。
换成 0.64 方针：阈值 0.45＋0.32 = **0.77 < 1.27**，一根弹簧针物理上不可能同时碰两根针脚；
0.77～1.77 mm 错位区是开路。`hardware/check_j2_mismate.py` 的并查集方法论照用，几何参数改这两个数即可。

**排布 = H2 pinout，动不了。** 你 D1 的 LEFT_SLOT.md 表：pin17 5V_IN 的邻居是 pin19 3V3、pin15 GPIO34（USB D+）、
pin18 5V_OUT、pin16 SDA、pin20 GND。整场沿行错一格（2.54）就把底座 5V 压到 3V3 或 USB D+。
出事需 ≥1.77 mm 错位，对导向公差 ±0.45 是 3.9 倍；排针本体（~26×9×5）被底座槽口卡住后定位应远好于此。**要进闸门。**

**底座侧不装针的位置就是天然隔离带**：pin18 5V_OUT、pin13/15 USB、pin10 EEPROM A0，底座一律不放弹簧针。
