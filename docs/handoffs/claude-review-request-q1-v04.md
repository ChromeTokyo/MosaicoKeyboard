## 1. 这件东西是什么

轨一（D-031）：用户即将收到 Mosaico 本体 ＋ 官方「Module Interaction」交互模块（一块 PCB ＋ 2×10 排针直插 Mosaico 侧槽 ＋ 两个键盘轴）。
官方模块**悬空挂在排针上**。轨一 = 一个 3D 打印件，**替换官方模块的底板**，把 Mosaico 也定位住，
让排针只走电、不承力；用户到货即打印即用（2 键），同时当轨二的测量夹具。

官方模块解析：`references/official-module-interaction/ANALYSIS.md`。方案 J 权威描述：`review/claude/option-j-seated.md`。

## 3. 八条硬要求（闸门逐条断言）

1. 四边保持：Mosaico 四条前缘都被压住，任一角不能抬起；不靠卡扣、不靠 Mosaico 任何边缘特征（圆角／玻璃到边／侧槽全未知）
2. 除压框（厚 ≤1.6）外托盘任何部分 Z ≤ 11.48（屏面）
3. Z ∈ [0, 11.48] 内托盘实体与 Mosaico 包络（45.19 见方 ＋ 2×0.3）相交为空
4. 不碰官方外壳：Z>0 在官方底板脚印内只能有官方底板本身
5. 排针安全靠装配顺序：先落到环形沿（±X 定位）→ 沿针轴推到止挡（此时才进针）→ 压框四颗螺钉。GAP 区 Z∈[2,9] 无实体
6. 可打印：PLA、0.4 喷嘴、壁 ≥1.2、悬空 ≤2、立柱壁 ≥1.5 环绕 Ø1.7
7. Mosaico ±X 面功能区（USB-C＋侧键／顶键＋扬声器，Z≈2～6）中央 34 mm 不被遮挡
8. 假设按 Q1-* 编号登记

## 5. 请你们回答的

1. **闸门抓得住上表的错吗？** 把 v0.3 的 STL 喂给 `check_quickstart.py`，它应当红。不红 = 闸门有洞，洞在哪。
2. **v0.4 的保持真的闭合吗？** 用截面／包围盒亲自量：四角抬起的自由度、压框压边量、立柱位置是否全在 Mosaico 脚印外。
3. **排针**：按 README 的装配顺序做一遍思想实验，哪一步可能横向加载排针；取出顺序对不对。
4. **可打印**：最薄壁、最长悬空、压框 1.6 厚跨 45 mm 的翘曲风险、立柱 Ø1.7 底孔在 0.4 喷嘴下实际会打成多大。
5. **官方件**：托盘会不会挡官方外壳卡合、挡键盘轴、挡排针出口（官方外壳朝 Mosaico 一侧壁的底边有约 24 mm 出口）。
6. **主控没想到的**——这一条最值钱。
