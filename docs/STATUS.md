## 5.2 实物到货前的推进边界

用户提出：实物到货前可否先把功能电路做完，大不了不下单打板。主控判定**可以，而且应该**，但需按下表区分，避免做了要推翻的部分。

| 可全速推进（不依赖实物） | 必须留住（依赖实物或触点方案决策） |
| --- | --- |
| F03 可复现基线修复——所有其他修复的前提 | PCB 最终布局与布线：触点是整板的定位基准 |
| F02 PCB 文件格式修复（纯工具链） | 板框尺寸、模块开孔、模块包络 |
| F01 网络误并修复（POGO_5V／BOOST_SW） | Pogo 针位置与压缩行程的冻结 |
| T05 对 A0 的完整独立电气审查：电源全状态、O04 I²C 电平、O05 电流热预算、O06 双路供电防反灌 | 外壳的精确配合面、壁厚与装配公差 |
| T07 电路修订版、计算与 BOM 选型 | 任何 G1 接口冻结动作 |
| 电源拓扑、充电与边用边充、防反灌方案 | 方案 B 相关的增量电路（未决时不要投入） |
| 器件选型与嘉立创供应／工艺核验（T04） | |
| 功能框图、电源状态表、测试点规划 | |
| 外壳的形态、握持、按键布局与人机（T13 范围） | |

**组织原则：把方案 A 当作必做核心，方案 B 当作可选增量。** 四个背部焊盘在两种方案下都存在，因此电源路径、充电、升压、防反灌、I²C 扩展器、电量计这些核心电路在两种方案下都要做，先做不会白做。方案 B 的增量（EEPROM 识别、UART 下载通路、USB 直通、额外 GPIO）作为后加模块，等决策后再接。这样触点方案的决策不会推翻已完成的工作。

**不下单打板确实没有金钱成本，但有两类隐性成本**：一是按未确认的触点几何把布局布完，返工的是整块板；二是为了迁就方案 A 的触点数量而在电路上做的取舍，若最终选方案 B 就白做。前者靠「不冻结布局」避免，后者靠上面的组织原则避免。

## 5.3 3D 打印机带来的两条额外路径

用户在日本本地有 3D 打印机，可随时打印验证。这使两件事不必等待国内批次：

1. **T16 已改写（原设想作废）。** `MOSAICO.3mf` 经元数据核实为 MakerWorld 模型包，**未核实为乐鑫官方发布**；且内部有螺柱与加强筋、封面图显示裸板直接装在框内、底缘止口是一块不在文件中的背盖的座——该壳很可能容纳的是 PCB 组件而非整机白壳。因此「打印件内腔 − 模块本体 = 装配间隙」的相减前提不成立，「整机 ≤ 41.88 见方」的推论作废。改为：打印后与实物比对，判定该壳对应裸板还是整机；整机尺寸以卡尺直接实测为准。详见 `review/claude/3mf-analysis.md`。
2. **T17 产品体量模型。** 按 T13 的形态方向打印握持体量件，验证长条形比例、握把深度、按键落点与拇指可达范围。这部分不含任何硬件配合尺寸，现在就能做，结论回写 T13。

两项都不产生可冻结的工程尺寸：打印件的尺寸误差、材料收缩与层厚效应必须单独记录，结论仍需 Chrome 采纳、Hiro 复核。

## 6. 主要风险

- **最后一道实测在日本**：需要通电才能发现的问题都在跨国运输之后暴露。补偿手段（测试点、分步上电、限流、可更换、可观测、备板备件一次寄足）已写入 `docs/TEAM_PLAN.md` 并作为 G3 放行前提，必须在设计阶段落实，事后补不了。
- **电池运输**：锂电池国际运输受限，电池是否随机寄送尚未确认；选型应优先考虑用户所在地可合法采购的规格。
- **实物到手不等于证据到手**：没有规程的随手测量不能用于冻结接口，必须按 T14 规程留照片与数据并经复核。
- **单点负荷**：Chrome 同时承担电气与机械，串行执行会拉长周期；按用户取舍不转移职责。
- **复核不可强制**：当前账号无 admin 权限，无法配置分支保护，非作者复核只能靠流程约束。
- **状态漂移**：各端在不同平台，状态不写回仓库就会丢失；进展同步已列为 `AGENTS.md` 强制项。
