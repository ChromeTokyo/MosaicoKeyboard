# ESP-Mosaico 底座统一接口约束

版本 **ICD-0.2-DRAFT，2026-09-20；未冻结、禁止作为制造尺寸**。维护／技术责任：Chrome；关键接口独立复核：Hiro；冻结提交与放行记录：Claude。当前写入分支 `chrome/t18-proposal-review`（PR #9 合入后的版本适用性修订）。本轮输入 main `edb5301`，原稿输入 `25c4902`；已纳入 `a9d383c` 的 D-009-R／D-010／D-011、`1030776` 的 PR #8 来源更正；A0 审查对象仍为 `3d5a112`，没有改动设计源。

`confirmed` 指指定官方文件明确画出／写出，不代表样机实测通过；`derived` 指计算或图面推断；`proposed` 指 Chrome 提出的设计要求或研究值；`unknown` 指仍需证据。**本文没有任何 measured／frozen 尺寸。** 各项变更均须检查末列影响范围；Hiro 复核未完成时不得自批 G1/G2/G3。

## 0. 目标板卡版本是接口前提

**到货CoreBoard／BaseBoard版本均unknown。** 用户提供的开箱视频约01:06显示`Baseboard-A V1.2`，约01:18显示`Coreboard V1.2`；中央未见下文四圆焊盘，边缘调试排也不同，见[视频证据](../review/chrome/T14/video-20260920/README.md)。这不是到货确认，也不凭版本号推定新旧。

以下E1/E2及四触点映射的`confirmed`只表示所引**V1.0资料**中的事实。四触点存在性、几何、上拉、电源路径、引脚兼容均不得无证据跨到V1.2。先取得完整原状照片与可见板号；不能为认版要求用户拆屏。未确认匹配前，A方案的J3与供电对应暂停，保留为V1.0研究分支；不把边缘调试排改名为四触点。

## 2. 坐标、镜像和接点编号（O03）

统一物理上边记为 **T↑**，以实物照片中的固定外壳边标记，不以屏幕自动旋转为准。先与 E1 Fig.7 的正读方向对齐再把测量录入；若有 90° 整机旋转，作为完整刚体变换记录，禁止只换丝印名称。

- 模块背面外视 R：观察者看向四焊盘；X_R 向右，Y_R 向 T↑；原点为模块外包络投影中心（W/H 待测）。
- 模块正面 F：屏幕朝观察者，T↑ 不变；背部焊盘的投影左右与 R 相反，它们不是从正面可见的焊盘。
- 底座顶视 D：观察者看向 Pogo 接触面，T↑ 与模块物理上边一致；X_D 向右、Y_D 向 T↑，Z_D 离开底座朝模块。Z=0 为设计支承面，具体高度待实测与结构方案。
- 两接触面面对面时，投影变换 **X_D = −X_R，Y_D = Y_R**；原点对齐仅是坐标定义，不声称触点组恰在板中心。模块背面法向与底座顶面法向相反。

```text
模块背面外视 R（T↑不变）       底座顶视 D（T↑不变）
             ↑ Y_R                         ↑ Y_D
   SDA    +    −    SCL           SCL    −    +    SDA
   P1    P2   P3    P4            J3.1 J3.2 J3.3 J3.4
             → X_R                         → X_D
             面对面贴合：左右翻转
```

| 背面照片编号（左→右） | 官方丝印／功能 | 底座接点编号（顶视左→右） | 电气证据级别 | 几何 |
| --- | --- | --- | --- | --- |
| P1 | SDA，GPIO0／I2C0_SDA | J3.4 SDA_HOST | E1/E2 confirmed；实物转接待复验 | x1,y1,d1 unknown |
| P2 | +，官方架构 5V_IN | J3.3 HOST_5V_IN | E2 p1 4P POGOPIN 为 5V_IN；+ 的逐焊盘物理路径 derived／待复验 | x2,y2,d2 unknown |
| P3 | −，GND 设计对应 | J3.2 HOST_GND | 丝印 confirmed；GND 物理导通待复验 | x3,y3,d3 unknown |
| P4 | SCL，GPIO1／I2C0_SCL | J3.1 SCL_HOST | E1/E2 confirmed；实物转接待复验 | x4,y4,d4 unknown |

J3 编号为本草案拟定映射，后续必须与 EDA 实际引脚和装配面逐项核对，不能仅按照片重新编号。**左右镜像会同时交换 SDA/SCL 与正负供电。** 印字、坐标图、机械防反、断电配对测试四者都必须验证；“I²C 不工作”不能作为安全的方向检测方法。

## 3. 几何研究与预留（O01/O02）

| 项 | 本轮结论 | 状态／关闭条件 | 变更影响 |
| --- | --- | --- | --- |
| A0 2.54 mm 间距 | 按 D-009-R 保留为有图像支持的**候选名义值**；不再重排成 2.70–2.77 mm | proposed；实物分方向标定／可追溯测量、Hiro 复核前，J3 仍 `POGO_GEOMETRY_UNVERIFIED` | 电气接点映射、J3、PCB、载板、模块仓 |
| 图像中心距 | 主控更正约 2.516 mm；本次脚本复跑约 2.517 mm、首末约 7.551 mm（细节见 E3） | derived；不得把与 2.54 的微小差值当真实生产偏差 | 研究模型参数，不直接写生产封装 |
| 焊盘直径 | 主控更正“约 1.55 mm”为线索；复跑发现其直径计算仍混合横纵尺度，严格分轴值见 E3。**本文件继续留 d1～d4 = unknown** | 需实物分别测横纵边界；不据 1.55 mm 选定针头 | 针头、有效落点、定位预算 |
| 四针相对坐标 | 研究模型用 `x_i=(i−2.5)·p`，i=1..4；实际允许四点独立调整，y_i 不强制相同 | proposed 参数化形式；共线性、等距性、绝对偏移均待实测 | 模块仓、板框、治具 |
| 研究载板预留 | 建议可更换四针小载板／独立定位嵌件，研究夹具整体 X/Y 各 **±1.0 mm** 调节范围，即每轴总行程 2.0 mm；候选间距可做 **2.44～2.64 mm** 小样参数扫描 | proposed 的调试范围，非来源于产品公差。样件无电或限于已审核的假负载；若实测超范围重做，不截断数据 | PCB 禁布、固定件、线束和压框；空间未知，能否实现待 T03 |
| 正式布局占位区域 | 以待选针筒／焊接盘包络 `B_x×B_y` 为基础，研究载板活动包络至少 `(B_x+2.0)×(B_y+2.0) mm`；额外加紧固、装配和走线净距 | derived 于上述调节方案；**B_x/B_y 和最终净距 unknown**，不能只按针尖直径留铜区 | PCB、结构和夹具 |

旧“第四针必须补 0.5～0.7 mm”已撤回，不再用它论证余量。调节行程是便于首轮定位的研究选择，不能吸收或掩盖正式接口误差。正式 PCB 不用长槽挪动带电 Pogo 充当装配公差；接点要在冻结载板上固定且可重复定位。

**落点预算（待数值化）：** 对每一点，最坏横向合成误差 `e_total` 必须满足 `e_total + r_tip + m_edge ≤ d_min/2`。其中 e_total 至少含实测误差、设备个体差、导向游隙、壳体／PCB／载板位置误差、针筒与针头偏摆、磨损和倾斜投影；采用最坏组合前不得默认统计抵消。有效针头接触半径 r_tip 以所选厂商图与压缩状态为准，边缘裕量 m_edge 待制定。所有项未填全前没有允许偏心量。

**高度与针力预算：** 对每个针 `c_min=H_free_min−g_max`、`c_max=H_free_max−g_min`；g 是针安装基准到触点接触面的实际间距，含板厚、平面度、翘曲、装配高度和倾斜。c_min/c_max 必须落入厂家推荐工作行程，并由硬限位阻止压到底。四针（B 为实际使用针数）合力、载板弯曲、壳体承力和偏心力矩须核算，不能由模块 PCB 或焊点承受按键载荷。

## 4. 方案 A／B 技术比较与当前建议

**先确认目标版本。若实物确有V1.0四焊盘，再优先验证A；B为条件性备选。本轮不选定或冻结任一方案。** 现有需求只有供电与 I²C 按键，A 可保留整机；B 只有在额外触点具有明确需求，或 A 电源／接触条件不能闭环，且无损可达性通过实测后才值得承担其代价。视频支持揭开外层薄片后看见焊点，不能保证焊点可作Pogo靶，也不等于已拆下BaseBoard。若 B 需要拆 BaseBoard、焊线或拆焊侧连接器，将触及“不改板、不焊线、完整可拆”的需求，不能默认为已获批准。

新增候选方向 **C：完整整机经侧面插座可拆转接**。仅作研究，须核对到货版pinout、侧向空间、连接器保持力与供电约束；未替代A/B裁决。若实物是视频布局，A先暂停，再比较B/C。

| 维度 | A：仅四个背部焊盘 | B：拆开可拆部件后，垂直接触模块通孔／调试点 |
| --- | --- | --- |
| 可用电气资源 | SDA/SCL、5 V 输入意图、GND；按键仍经 IO 扩展器 | 2×10 模块接口含 5V_IN、GND、3V3/5V 输出、I²C、UART、部分 USB 和 GPIO；6 调试点另含 BOOT/EN |
| 现有需求适配 | 足够表达现有供电／轮询按键架构，无独立 MCU | 多触点不自动带来收益；额外 GPIO、USB、调试须逐项论证，GPIO57 关机请求并不在公开 H1/H2／6 调试点表中 |
| 接触面 | 设计成平面扩展焊盘，仍需尺寸、镀层与接触寿命证据 | 空孔可能使针头落空，环铜／锡面与突出焊脚不等价于规范 Pogo 靶；不得靠刮锡扩大落点 |
| 机械和维修 | 四针、针力较少；保留背部结构、支承和散热 | 接点更多、力更大且高度可能不一；背部构件性质与可拆路径未证实，可能损失承力／遮蔽／散热 |

| 固件／资源 | 避开既有地址、评估热插拔及断电状态 | EEPROM 0x50/0x51 是槽位标识，不是仅接通这两个地址即可成为受支持模块；GPIO14/39 选择和BSP内容需官方方案。复用GPIO不能破坏音频等原功能 |

### 镜像／反接保护技术取舍

采纳“必须处理反接”的目标，但**不把底座正输出串 PMOS 理想二极管或肖特基，单独认定为镜像反接保护**。原因是错误发生在其下游触点映射：底座仍正向输出到模块“−”，模块“+”接底座回路，串联器件可能仍正向导通；I²C 或另一个 USB 的地还会形成旁路。CoreBoard已有D10也不能在BaseBoard网络未知时替整个装置兜底。

本轮拟定四项并行要求：① 模块仓用非对称定位和硬限位，错误朝向不能压到电触点；② 载板装配防反，顶视丝印与离线导通配对，生产测试先用无源检具；③ 接口未正确就位时输出默认关闭，研究独立机械到位联锁，不占四线I²C假装识别；④ 输出可关断限流、防反灌并评估断开供电和信号旁路。失效分析须覆盖装错载板、偏移、斜插、单针先接及双USB共地。

具体拓扑、是否需要双极隔离及其检测方法留到T07/H1，器件未选定、未验证。**限流不等于可允许反向电压**；未证明错误接触安全前，不以“串了保护”放行实物带电插接。

### 供电状态覆盖（T05/T07/G6 共用）

D=底座USB输入，B=底座电池，N=原生USB接外部电源；下表遍历8种组合。每行还应覆盖模块工作／关机、板载电池状态、GPIO60高低（仅在MCU有效供电时）、底座接入／脱离、Codec开关、接触抖动和掉电先后；原生USB作为source接负载另建子表，不能混同N输入。

| D | B | N | 必须验证的重点 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 内置小电池可能使主机仍带电；底座I²C不得被幽灵供电 |
| 0 | 0 | 1 | 主机独立USB供电，底座关断；检查通过信号和接点向底座回灌 |
| 0 | 1 | 0 | 电池升压、欠压、输入脉动、插接涌流 |
| 0 | 1 | 1 | 双电源优先级、反向电流及两地连接路径 |
| 1 | 0 | 0 | **无底座电池仅USB即可逐级测电源**，先不接主机 |
| 1 | 0 | 1 | 双USB无底座电池状态，断开任一路的瞬态 |
| 1 | 1 | 0 | 边用边充、电流分配、净充电能力、温升与低电量 |
| 1 | 1 | 1 | 两USB+两电池的最复杂状态，切换与故障恢复 |

表中无通过阈值，状态覆盖不等于设计通过。T07需给出正常和故障电压／电流／温升阈值、条件和测点，Hiro审核后再由用户执行G6。
