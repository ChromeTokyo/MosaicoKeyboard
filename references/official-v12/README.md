## 从底板内侧图直接读到的丝印（confirmed）

底板**内侧**（拆下四颗螺丝后朝内的那一面）有四个焊盘，丝印为：

```
5V-I   3V3          （位于 60-pin BTB 连接器上方）
GND    VBAT5V-O     （位于 BTB 连接器下方）
```

底板**顶边有两个缺口**（图中橙色引线所指），扩展指南正文说明「新接入硬件的双绞线，可从底板缺口处穿入」。

即：官方认可的扩展取电流程是「拆底板四颗螺丝 → 焊到内侧焊盘 → 线从顶边缺口穿出」。

**该流程与本项目「不拆解、不焊线」的硬性约束冲突**，且相对走模块槽属多此一举，仅作兜底记录。

## 官方标称整机尺寸（derived，来源为官方视频简介，非标注图纸）

宽 45.19 mm、厚 11.48 mm、重 33 g。与开箱录屏中卡尺读数 45.27 mm 量级吻合。**不得作为工程尺寸**，仍须实测。
