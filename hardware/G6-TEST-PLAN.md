# G6 日本端整机验收测试计划（方案 D＋G）

日期：2026-09-20。输入提交：`origin/main` `1af3c36`。分支：`claude/design-d/icd`。配套：`hardware/ICD-0.2-DRAFT.md`（接口与网络名）、`hardware/ASSUMPTIONS.md`（假设编号）、`docs/INTERFACE_CONTROL.md` 第 5 节供电八态表、`docs/TEAM_PLAN.md` 第 6 节 G6 定义与 G3 补偿约束。

## 0. 定位、职责与规则

- 按 `docs/TEAM_PLAN.md`：G6 由 **Chrome 提出测试规程、条件与通过阈值；Hiro 独立复核规程可执行性；用户在日本执行并记录；Claude 汇总与放行记录**。本稿是 Chrome 下线期间的主控草案，**全部通过阈值标「待 Chrome 定义」**，本稿不自行设定任何阈值；Hiro 复核前不得据以判定通过。
- 执行人是没有工程调试能力预设的用户；每一步写成可独立执行的动作，凡需示波器/逻辑分析仪的项目标「可选」，无该仪器时记录「未执行」而非跳过不记。
- **安全规则**：① 任何一步电压/电流读数超出待定义阈值、闻到异味、任何器件手感发热明显，立即断开 USB 与电池，拍照，停止后续步骤；② 锂电池操作在不燃桌面、周围无易燃物；③ 首次上电顺序严格按第 3 节 A 段，**不得跳过「不接 Mosaico 先测底座」**；④ 不拆 Mosaico、不焊线、不带电插拔 H2 槽位（模块板一经插入槽位即不再拔出，除 G6-C3 一次性例外）。
- 所有测试点名称、网络名以 `hardware/ICD-0.2-DRAFT.md` 第 9 节为准；测试点物理位置由底座/模块板任务在 PCB 上以丝印标注并在其 README 给照片编号，本稿只引用名称。

### B 段：供电八态（硬约束 8 双供电）

D=底座 USB 输入，B=底座电池接入，N=原生 USB 接外部电源（经在线表）。每态停留 ≥ 2 min，记录 `DOCK_5V` 电压、底座 USB 电流、原生 USB 电流、`VBAT`、Mosaico 开机/充电指示；态切换时观察 Mosaico 是否复位。

| 项 | D | B | N | 重点 | 阈值 |
| --- | --- | --- | --- | --- | --- |
| G6-B1 | 0 | 0 | 0 | Mosaico 内置电池维持时，`KEY_*`、`DOCK_SDA/SCL` 针对 `DOCK_GND` 电压（EL-D-11 反向：主机上拉是否把底座信号针抬起，应仅为主机上拉、无电流路径） | 定性 |
| G6-B2 | 0 | 0 | 1 | **只原生 USB**：测底座 `DOCK_5V` 节点电压、流入底座方向电流（AS-11、TH-06）；`DOCK_SDA/SCL` 针电压 | TH-06 |
| G6-B3 | 0 | 1 | 0 | 只电池供主机：能否开机、`VBAT` 跌落、插接时是否复位（AS-19） | TH-05 |
| G6-B4 | 0 | 1 | 1 | 电池 + 原生 USB：两路电流方向与大小，底座是否被反灌 | TH-06 |
| G6-B5 | 1 | 0 | 0 | 只底座 USB、无电池：主机开机与充电；这是 A 段已覆盖的最简态，复测一次 | TH-01 |
| G6-B6 | 1 | 0 | 1 | 双 USB 无电池：拔任一路时主机是否复位 | 定性 + TH-06 |
| G6-B7 | 1 | 1 | 0 | **边用边充**：主机满负载（屏最亮、Wi-Fi、音频）时净充电与温升；AS-29 主机关机放回底座 30 min 后电量变化 | TH-04、TH-07 |
| G6-B8 | 1 | 1 | 1 | 最复杂态：各路电流、切换、故障恢复 | TH-06 |

补充：G6-B9 在 B7 条件下用原生 USB 在线表单独测 Mosaico 峰值与持续电流（Mosaico 不在底座、只原生 USB），回填 AS-09。

## 4. 故障树（用户自查用，不替代 Chrome 分析）

| 现象 | 先查 | 再查 |
| --- | --- | --- |
| A2 `DOCK_5V` 无输出 | `VBUS_IN` 有无；升压使能是否纯硬件（EL-D-01：不应依赖任何主机信号） | 限流器件故障指示；A1 是否有短路 |
| A6 `SLOT_3V3` 焊盘有电压 | 违反硬约束 3：查模块板/底座是否误接 3V3 到针 | 立即停止，不得接 Mosaico |
| C1 未识别 | A7 主机开机后 `TP_3V3` 是否 3.3 V（AS-13）；模块板 A0 焊盘电平；镜像是否空白 | 上拉（AS-14）；H2 方向（AS-17） |
| C1 CRC 失败 | 镜像烧录回读是否一致 | 总线质量（E 段） |
| D1 某键无反应 | A6 该键通断；PINMAP 与固件是否同版 | 弹簧针该列是否到位（G2 压降） |
| D1 键名错位 | PINMAP.md 版本；模块板焊盘序与 H2 方向（AS-17） | 弹簧针 X 错位 1 列（ICD 3.3 节二级表） |
| B2 流入底座电流超阈值 | 防反灌器件方向/失效 | 停止双供电测试 |
| G1 插入时 Mosaico 复位 | 记录次数；AS-19 | 先接触次序方案（ICD 3.3 节） |

## 5. 判定与遗留

- 每项 `VERDICT` 只允许 PASS / FAIL / 未执行 / 阈值未定义。**阈值未定义的项不得写 PASS**。
- G6 通过条件（由 Chrome 定义、Hiro 复核后填入）：待定义。本稿建议的最低集合：A1–A7 全 PASS、B2/B4/B6/B8 反向电流 PASS、C1/C5 PASS、D1–D3 PASS、F1 PASS、G3 PASS；其余项允许作为遗留登记。
- 遗留项写入 `docs/DESIGN_STATUS.md` 并与 `hardware/ASSUMPTIONS.md` 对应编号联动；证伪的假设改 `FALSIFIED`，触发 D-017 第 ③ 步改设计。
