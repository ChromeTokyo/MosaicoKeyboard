# 错位枚举证据目录

`hardware/check_j2_mismate.py` 是**常驻闸门**，改逐针分配后必须跑到退出码 0。

本目录是它的**审计轨迹**：三版竞争分配（防错优先／可制造优先／最坏情况优先）
各自的穷举枚举脚本与实跑结果。它们不是常驻校验，**不要在 CI 里跑**，
留在这里是为了让「为什么否决 P2」「为什么两版安全数字相同却选了这一版」可复核。

要点：**P2（角位 5V ＋ 孤立哑焊盘护城河）被判不安全**，触发位移只有 1.090 mm。
机理是：焊盘 Ø2.0 ＋ 针尖 Ø0.9 使搭接阈值 R = 1.45 mm **大于**半间距 1.27 mm，
半格错位时一根针同时压住相邻两块铜——而**孤立铜不是绝缘体，是一段没有端点的导线**，
它不终止链条，只延长链条：`焊盘 → 针 → 焊盘 → 针 → 焊盘 …`，一路走到 KEY 焊盘。

对照实验（同一脚本 `P2_nocu` 一档）：把哑位改成**模块侧整片无铜（裸阻焊）**、
底座照装针，致命触发立刻从 1.090 mm 回到 3.630 mm、腔体内 0 起。
**问题不在「哑位」这个想法，在它保留了铜。**
