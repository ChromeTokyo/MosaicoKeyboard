# 外壳选材：PLA-CF 能用在哪、不能用在哪

2026-09-21 用户提出打算用 **PLA-CF（碳纤维填充 PLA）** 做外壳。结论先说：

> **外观与结构壳体用 PLA-CF 很合适；但卡扣悬臂绝对不能用 PLA-CF，本设计正好重度依赖卡扣。**
> 建议**分件选材**，而不是整机一种料。

## 1. PLA-CF 好在哪（对本项目而言）

| 特性 | 对本项目的价值 |
| --- | --- |
| 弹性模量约为纯 PLA 的 1.5～2 倍 | 167 mm 长的掌机壳体，握持时中段不能有可感知的挠曲。这是 PLA-CF 最大的加分项 |
| 翘曲小、收缩率低 | 整机 167 × 101.5 mm 是大件，翘曲直接毁掉配合 |
| 尺寸稳定性好 | 落入槽、定位孔、弹簧针配合面都吃尺寸精度 |
| 哑光、有纤维纹理，不反光 | 「像市售产品」这条产品目标，PLA-CF 的表观质感确实接近注塑件，比亮面 PLA 强得多 |
| 打印温度与纯 PLA 接近，不需要封箱 | 用户在家打，ABS/ASA 的翘曲与气味是实际障碍 |

## 2. PLA-CF 不能用在哪 —— 卡扣，而且本设计重度依赖卡扣

`MATING.md` 第 4 节定的承力闭环是：

```
弹簧针 (+Y) → 触点板 → J3 → 槽板 → 壳体足 → 壳体 ±Z 外表面卡爪 (−Y) → 底座卡扣 → 底座结构
```

两条硬要求：

- **卡扣保持力 ≥ 30 N（两处各 ≥ 15 N）**，而且是**持续**载荷——弹簧针名义 9.6 N、最坏 14.4 N
  一直往外顶，卡扣一直扛着，不是间歇受力。
- 设计工况含 **50 g 跌落冲击**（`AS-31-mm-16`）。

### 2.1 装配应变：PLA-CF 的许用值不够

悬臂卡扣根部最大应变 `ε = 3·t·δ / (2·L²)`。按标定件 D 组的悬臂（L = 12 mm、t = 1.6 mm）：

| 过盈 δ | 根部应变 ε |
| --- | --- |
| 0.20 mm | 0.333 % |
| 0.30 mm | 0.500 % |
| 0.40 mm | 0.667 % |
| 0.50 mm | 0.833 % |

反复装拆的许用应变，工程经验取断裂伸长率的 30 %：

| 材料 | 断裂伸长率（典型） | 许用应变 | 本设计 0.3 mm 过盈够不够 |
| --- | --- | --- | --- |
| **PLA-CF** | **1～2 %** | **0.45 %** | **0.500 % > 0.45 %，不够** |
| PLA | 5～6 % | 1.65 % | 够 |
| PA-CF（尼龙碳纤） | 3～5 % | 1.20 % | 够 |
| PETG | 10～20 % | 4.50 % | 余量 9 倍 |
| ABS/ASA | 10～25 % | 5.40 % | 余量 10 倍 |

**碳纤维提高刚度的代价就是断裂伸长率掉到纯 PLA 的四分之一左右**，而卡扣要的恰恰是伸长率。
PLA-CF 只有在过盈压到 0.2 mm 时才勉强合格，而 0.2 mm 过盈能不能给到 15 N 保持力，
以及在 3D 打印公差下 0.2 mm 会不会直接变成 0，都很悬。

### 2.2 层间结合：碳纤维还会再削一刀

碳纤维填充普遍**降低**层间结合强度（纤维打断了层间的聚合物缠结）。卡扣悬臂的弯曲应力
如果穿层，实际强度比上表还低。这条对任何打印件都适用，但 CF 料更敏感。

### 2.3 蠕变：持续 15 N 是 PLA 类材料的经典失效场景

PLA 系在室温下就会蠕变。卡扣**永久**扛着 15 N，几周到几个月后逐渐张开，
弹簧针预压随之衰减 → 接触压力下降 → 接触电阻上升 → 通信或供电间歇性故障。
这是一个**装配时完全正常、几个月后才出现**的失效，最难排查。

碳纤维会减轻但不会消除蠕变，因为蠕变发生在聚合物基体里。

## 3. 另外两条整机层面的风险（与卡扣无关，但一样要决定）

### 3.1 跌落脆裂

掌机是拿在手上、会掉在地上的东西。PLA-CF 脆，跌落容易直接裂而不是变形吸能。
`AS-31-mm-16` 的 50 g 工况本来就写着「无法在家验证，只做设计余量」。
如果整机外观件用 PLA-CF，摔一次可能就报废；PETG/ABS 更可能只是留个白印。

### 3.2 玻璃化温度没变

**碳纤维不提高 Tg。** PLA 的 Tg 约 55～60 °C，PLA-CF 还是 55～60 °C
（热变形温度 HDT 在负载下会因刚度提高而略升，但 Tg 是聚合物本征属性，不变）。

这台机器里有锂电池，会被随身带。日本夏天车内仪表台可到 70～80 °C。
**PLA-CF 壳体在车里放一下午会软化变形，而且是带着电池一起。**
ABS/ASA 的 Tg 约 100 °C，PETG 约 80 °C，PA 更高。

这一条是否接受，取决于用户实际会不会把机器留在车里——这是**用户的使用场景决定，不是工程能替他决定的**。

## 4. 建议的分件选材

| 件 | 材料 | 理由 |
| --- | --- | --- |
| 上壳、下壳（外观与主结构） | **PLA-CF** | 刚度、哑光质感、翘曲小，是它的强项 |
| 键帽 | **PLA-CF** | 受压不受弯，且表观质感直接影响「像市售产品」 |
| 上压框主体 | **PLA-CF** | 主要受压，截面大，应力很低 |
| **卡扣／任何弹性悬臂** | **PETG（首选）或 PA-CF** | 唯一的硬性排除项，理由见第 2 节 |
| 模块板保护壳的领口夹持衬 | 闭孔泡棉／TPU 0.5 mm | 已定，与本讨论无关 |

卡扣改成**独立件**，用螺钉或燕尾装到 PLA-CF 壳体上。件很小，换一卷料打几分钟。

### 4.1 更好的一条路：把持续载荷从卡扣移到螺钉

现在卡扣同时承担两件事：**持续扛 15 N 预压**，和**免工具取放 Mosaico**。这两件事可以拆开：

- 上压框改为 **M2 螺钉压紧**，持续的 9.6～14.4 N 由钢螺钉承担，塑料只受压不受弯，蠕变问题消失；
- 卡扣只负责免工具取放，保持力要求从 ≥ 15 N 降到几牛顿，过盈可以压到 0.2 mm 以下，
  **PLA-CF 就够用了**，分件选材也不再必要。

代价是取下 Mosaico 需要拧两颗螺钉。**这是产品定位问题，不是工程问题**：

- 若 Mosaico 是「装上去基本不取」的（方案 D＋G 本来就假定模块板插上就不拔），**螺钉路线明显更优**；
- 若希望随时徒手取下 Mosaico 换用途，才需要保留大保持力卡扣，那就必须分件选材。

**这一条需要用户决定**，决定之后 `MATING.md` 第 4 节的整个力闭环要重做。

## 5. 打印这一侧的三条具体事项

1. **必须换硬化喷嘴。** 碳纤维磨蚀性强，黄铜喷嘴几十小时就会磨大孔径，之后所有尺寸全偏。
   如果现在用的是原装黄铜喷嘴，**先换再打标定件**，否则 A/B 两组量到的是磨损过程不是打印机能力。
2. **卡扣的打印方向要让弯曲应力沿着层走，不能穿层。** 这条对 PLA-CF 尤其要紧。
3. **确认具体牌号的 TDS。** 「PLA-CF」是个大类，有些其实是 PLA+PHA+CF 的增韧共混，
   断裂伸长率能到 3～4 %，那第 2.1 节的结论要放宽。**看两个数：断裂伸长率、HDT。**
   查到之后回填本文件第 2.1 节的表。

## 6. 对标定件的影响（现在就能做的验证）

`mechanical/test-coupons/fit_ladder.scad` 的 D 组（卡扣过盈 0.20/0.30/0.40/0.50）
**正好就是上面这套推导的实测验证**。

建议：**D 组和 E 组各打一份 PLA-CF、一份 PETG**。件很小，多打一份成本几乎为零，
但能直接用手感和「反复十次后爪根有没有发白／裂」把第 2.1 节的表证实或推翻。

A／B／C 三组按最终外观件的材料（PLA-CF）打即可——它们量的是尺寸行为，与外观件同料才有意义。

**C/D/E 三组全部是手感判断，不需要游标卡尺**（能不能徒手插入、有无卡滞、有无「咔」的到位感、
手掰断不断）。只有 A 组（高度）与 B 组（柱径）要卡尺。卡尺未到期间，这三组可以先做。
