2026-09-21 用户确定用 **eSUN ePLA-CF**（碳纤维增强 PLA）做外壳。

> **修订说明（同日，拿到原厂 TDS 之后）**
>
> 本文件最初版本用「PLA-CF 通用值」估算，取断裂伸长率 1～2 %，据此判定

## 1. PLA-CF 好在哪（对本项目而言）

| 特性 | 对本项目的价值 |
| --- | --- |
| **弯曲模量 5003 MPa**（纯 PLA 约 2900～3600） | 167 mm 长的掌机壳体，握持时中段不能有可感知的挠曲。这是它最大的加分项，且是 TDS 实数不是估计 |
| 翘曲小、收缩率低 | 整机 167 × 101.5 mm 是大件，翘曲直接毁掉配合 |
| 尺寸稳定性好 | 落入槽、定位孔、弹簧针配合面都吃尺寸精度 |
| 哑光、有纤维纹理，不反光 | 「像市售产品」这条产品目标，PLA-CF 的表观质感确实接近注塑件，比亮面 PLA 强得多 |
| 打印温度与纯 PLA 接近，不需要封箱 | 用户在家打，ABS/ASA 的翘曲与气味是实际障碍 |

## 2. PLA-CF 不能用在哪 —— 卡扣，而且本设计重度依赖卡扣

`MATING.md` 第 4 节定的承力闭环是：

```
弹簧针 (+Y) → 触点板 → J3 → 槽板 → 壳体足 → 壳体 ±Z 外表面卡爪 (−Y) → 底座卡扣 → 底座结构
```

两条硬要求：

- **卡扣保持力 ≥ 30 N（两处各 ≥ 15 N）**，而且是**持续**载荷——弹簧针名义 9.6 N、最坏 14.4 N
  一直往外顶，卡扣一直扛着，不是间歇受力。
- 设计工况含 **50 g 跌落冲击**（`AS-31-mm-16`）。

### 2.1 装配应变：按真实 TDS 重算，eSUN ePLA-CF 是够的

悬臂卡扣根部最大应变 `ε = 3·t·δ / (2·L²)`。按标定件 D 组的悬臂（L = 12 mm、t = 1.6 mm）：

| 过盈 δ | 根部应变 ε |
| --- | --- |
| 0.20 mm | 0.333 % |
| 0.30 mm | 0.500 % |
| 0.40 mm | 0.667 % |
| 0.50 mm | 0.833 % |

反复装拆的许用应变，工程经验取断裂伸长率的 30 %。
TDS 的 4.27 % 是注塑试样值，打印件须折减，故列三档：

| 取值口径 | 断裂伸长率 | 许用应变（30 %） | 0.3 mm 过盈（0.500 %） | 0.5 mm 过盈（0.833 %） |
| --- | --- | --- | --- | --- |
| 注塑试样（TDS 原值） | 4.27 % | 1.281 % | ✓ 裕度 2.6 倍 | ✓ 裕度 1.5 倍 |
| 打印件取 IM 的 50 % | 2.13 % | 0.640 % | ✓ 裕度 1.3 倍 | ✗ 不够 |
| 打印件取 IM 的 35 %（保守） | 1.49 % | 0.448 % | ✗ 刚好不够 | ✗ 不够 |

**结论：过盈控制在 0.3 mm 以内时，eSUN ePLA-CF 做卡扣在中等折减口径下是站得住的**，
但在保守折减口径下不成立。折减系数取多少是**实测问题不是查表问题**——
标定件 D 组（PLA-CF 与 PETG 各打一份、反复十次看爪根发不发白）正是为此设计的。

对比参考（均为注塑试样口径）：

| 材料 | 断裂伸长率 | 许用应变 |
| --- | --- | --- |
| **eSUN ePLA-CF** | **4.27 %（TDS 实数）** | **1.281 %** |
| PLA（通用） | 5～6 % | 1.65 % |
| PA-CF（尼龙碳纤） | 3～5 % | 1.20 % |
| PETG | 10～20 % | 4.50 % |
| ABS／ASA | 10～25 % | 5.40 % |

### 2.2 层间结合：碳纤维还会再削一刀

碳纤维填充普遍**降低**层间结合强度（纤维打断了层间的聚合物缠结）。卡扣悬臂的弯曲应力
如果穿层，实际强度比上表还低。这条对任何打印件都适用，但 CF 料更敏感。

### 2.3 蠕变：持续 15 N 是 PLA 类材料的经典失效场景（**这条没有被 TDS 推翻**）

PLA 系在室温下就会蠕变。卡扣**永久**扛着 15 N，几周到几个月后逐渐张开，
弹簧针预压随之衰减 → 接触压力下降 → 接触电阻上升 → 通信或供电间歇性故障。
这是一个**装配时完全正常、几个月后才出现**的失效，最难排查。

碳纤维会减轻但不会消除蠕变，因为蠕变发生在聚合物基体里。

## 3. 另外两条整机层面的风险（与卡扣无关，但一样要决定）

### 3.1 跌落脆裂

掌机是拿在手上、会掉在地上的东西。PLA-CF 脆，跌落容易直接裂而不是变形吸能。
`AS-31-mm-16` 的 50 g 工况本来就写着「无法在家验证，只做设计余量」。
如果整机外观件用 PLA-CF，摔一次可能就报废；PETG/ABS 更可能只是留个白印。

### 3.2 耐热：**HDT 53 °C 是 TDS 实数，比我原先估的还低**

我原先按 Tg 55～60 °C 估。**TDS 给的热变形温度是 53 °C，而且是在很轻的 0.45 MPa 负载下测的**
（GB/T 1634）。1.8 MPa 口径会更低。原厂对「连续使用温度」与「最高短期使用温度」都标 **N/A**，
等于不给任何耐热承诺。

这台机器里有锂电池，会被随身带。**日本夏天车内仪表台可到 70～80 °C，远超 53 °C。**
放一下午，壳体会软化变形，而且是带着电池一起。

参考：PETG 的 HDT 约 70 °C，ASA／ABS 约 95～100 °C，PA-CF 更高。
用户手上这卷 ePLA-CF 的同一个卖家页面里就有 **ASA+** 与 **PA-CF** 可选。

**处置建议：首版仍用 ePLA-CF**——首版的任务是验证几何与手感，不是过车内高温；
ePLA-CF 好打、刚度高、尺寸稳，正合适。
**但把「HDT 53 °C」登记为已知限制**，在做「日常随身携带版」之前必须重新选材，
或者接受「不可留在车内／阳光直射处」这条使用约束。**这是使用场景问题，由用户知情后决定，不由工程代决。**

### 2.4 那么 D-026（承力改螺钉）还成不成立？——成立，但理由从四条减到三条

`docs/DECISIONS.md` 的 D-026 当时列了四条理由。按真实 TDS 复查：

| 原理由 | 现状 |
| --- | --- |
| ① 蠕变消失 | **成立且加强**。HDT 仅 53 °C、连续使用温度原厂标 N/A，室温长期承载没有任何背书 |
| ② 两个已知力矩归零 | **成立**。纯几何，与材料无关 |
| ③ 允许整机单一材料 | **作废**。既然 ePLA-CF 本来就能做卡扣（0.3 mm 过盈以内），本就不需要两种材料，这条理由不成立 |
| ④ 对打印公差极度宽容 | **成立**。纯装配，与材料无关；且直接对着用户指出的打印迭代瓶颈 |

**净结论：D-026 不撤回。** 决定性的是 ① 与 ④——蠕变是一个几个月后才显形、
而我们的验收链几乎捕获不到的失效；公差宽容直接压缩打印迭代轮次。
但 ③ 必须从决策依据里划掉，**不能让一个被推翻的论据继续挂在那里当支撑**。

## 4. 建议的分件选材

| 件 | 材料 | 理由 |
| --- | --- | --- |
| 上壳、下壳（外观与主结构） | **PLA-CF** | 刚度、哑光质感、翘曲小，是它的强项 |
| 键帽 | **PLA-CF** | 受压不受弯，且表观质感直接影响「像市售产品」 |
| 上压框主体 | **PLA-CF** | 主要受压，截面大，应力很低 |
| 非承力定位卡点（若保留） | **ePLA-CF 可用**，过盈 ≤ 0.3 mm | 按第 2.1 节重算后成立；承力路径已由 M2 螺钉接管（D-026） |
| 模块板保护壳的领口夹持衬 | 闭孔泡棉／TPU 0.5 mm | 已定，与本讨论无关 |

**分件选材的必要性已随第 2.1 节的重算而消失**：整机可以只用 ePLA-CF 一种料。
若 D 组实测发现打印件折减比预期严重，再把定位卡点单独换 PETG 打，届时件很小、换料几分钟。

### 4.1 更好的一条路：把持续载荷从卡扣移到螺钉

现在卡扣同时承担两件事：**持续扛 15 N 预压**，和**免工具取放 Mosaico**。这两件事可以拆开：

- 上压框改为 **M2 螺钉压紧**，持续的 9.6～14.4 N 由钢螺钉承担，塑料只受压不受弯，蠕变问题消失；
- 卡扣只负责免工具取放，保持力要求从 ≥ 15 N 降到几牛顿，过盈可以压到 0.2 mm 以下，
  **PLA-CF 就够用了**，分件选材也不再必要。

代价是取下 Mosaico 需要拧两颗螺钉。**这是产品定位问题，不是工程问题**：

- 若 Mosaico 是「装上去基本不取」的（方案 D＋G 本来就假定模块板插上就不拔），**螺钉路线明显更优**；
- 若希望随时徒手取下 Mosaico 换用途，才需要保留大保持力卡扣，那就必须分件选材。

**这一条需要用户决定**，决定之后 `MATING.md` 第 4 节的整个力闭环要重做。

## 5. 打印这一侧的三条具体事项

1. **必须换硬化喷嘴。** 碳纤维磨蚀性强，黄铜喷嘴几十小时就会磨大孔径，之后所有尺寸全偏。
   如果现在用的是原装黄铜喷嘴，**先换再打标定件**，否则 A/B 两组量到的是磨损过程不是打印机能力。
2. **卡扣的打印方向要让弯曲应力沿着层走，不能穿层。** 这条对 PLA-CF 尤其要紧。
3. ~~确认具体牌号的 TDS。~~ **已完成**：eSUN ePLA-CF TDS V4.0（2023-07）已归档，
   断裂伸长率 4.27 %、HDT 53 °C，第 0 节与第 2.1 节均已按实数重写。
   当初「有些其实是增韧共混，断裂伸长率能到 3～4 %，那结论要放宽」的猜测，
   **实际情况比猜测还好（4.27 %）**。

## 6. 对标定件的影响（现在就能做的验证）

`mechanical/test-coupons/fit_ladder.scad` 的 D 组（卡扣过盈 0.20/0.30/0.40/0.50）
**正好就是上面这套推导的实测验证**。

建议：**D 组和 E 组各打一份 ePLA-CF、一份 PETG**。件很小，多打一份成本几乎为零。

**D 组现在要回答的问题变了**：不再是「PLA-CF 能不能做卡扣」（TDS 说能），
而是「**打印件相对注塑试样的折减系数是多少**」——第 2.1 节那三档（100 %／50 %／35 %）
里，这台机器加这卷料落在哪一档。
判法：0.3 mm 那根（根部应变 0.500 %）反复十次后爪根发不发白、裂不裂。
- 不发白 → 折减不严重，落在 50 % 以上档；
- 发白或开裂 → 折减严重，落在 35 % 档，定位卡点须改 PETG。

A／B／C 三组按最终外观件的材料（PLA-CF）打即可——它们量的是尺寸行为，与外观件同料才有意义。

**C/D/E 三组全部是手感判断，不需要游标卡尺**（能不能徒手插入、有无卡滞、有无「咔」的到位感、
手掰断不断）。只有 A 组（高度）与 B 组（柱径）要卡尺。卡尺未到期间，这三组可以先做。
