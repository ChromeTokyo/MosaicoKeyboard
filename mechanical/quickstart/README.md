# 轨一：官方 Module Interaction 加固延伸托盘

## 这是什么

替换官方模块的 3D 打印**底板**。官方底板全部特征原样保留（`import` 官方 GLB 导出的 STL，
与官方外壳的卡合面零改动），再加一块通底托盘把 **Mosaico 也定位住**。
于是 Mosaico 与模块的相对位置由这一块塑料锁死，2×10 排针**只走电、不承力**。

官方原设计里模块悬空挂在排针上——本体重量、按键力、传感器全部经 20 根针进 Mosaico 母座焊点。这正是要改掉的。

```
      ┌──────────────────────────┬───────────────┐
      │  Mosaico（背面朝下）      │  官方模块       │  ← 两者背面同在一个平面
      │  三面唇边框住，中央开空    │  官方 PCB 4 颗   │
      │                          │  M2×6 自攻      │
      └──────────────────────────┴───────────────┘
      ═══════════════ 通底托盘 2.0 mm ═══════════════
```

## 装配（在官方六步之上只多一步）

1. 打印 `extended_baseplate.stl`（PLA 即可，与官方底板同参数：0.2 层高、3 壁、25 % 填充）。
2. **不打印官方底板**——本件替代它。官方**外壳**照常打印。
3. 官方 PCB 对孔放到本件的模块区（4 个螺柱与官方底板同位），4 颗 M2×6 自攻。
4. 官方外壳对齐卡入（与官方步骤 4 相同——卡合面没变）。
5. 装透镜、键盘轴（官方步骤 5、6）。
6. **Mosaico 背面朝下放进托盘的唇框，沿 −X 方向推向模块，排针插入 H2。** 唇框三面定位，朝模块一面敞开。

## 用它当夹具能量到的（直接喂轨二）

装好之后不拆，量：
1. 排针从模块外脸露出的长度（→ C1 针头长）
2. 两排针中心到模块前脸／背面的距离（→ H2 两排的 Z 位置，AS-04）
3. 针截面是否 0.64 方（→ 搭接阈值计算）
4. 模块壳实际厚度是否 10.90（→ 与 Mosaico 11.48 的高差）
5. `GAP` 实际值
