# 轨一：官方 Module Interaction 加固延伸托盘（v0.3）

## v0.3 回答用户的三问

**「靠这两个卡扣吗？」** 不靠了。v0.2 的两个卡舌撤下（保留为 `RETAIN="hook"` 选项，不推荐）。

**「Mosaico 上有给你卡住的位置吗？」** **不知道。** AS-01 只有外形尺寸，没有边缘轮廓——圆角多大、玻璃是否到边、
侧面有没有槽，全部未知。v0.2 的钩子搭在屏面边缘 0.5 mm 上，等于拿钩子压玻璃边、还可能从圆角滑掉。
**所以 v0.3 默认改成不依赖 Mosaico 任何边缘特征的方式**：一根**螺钉压条**（`RETAIN="bar"`）。
另备一个 `RETAIN="tongue"` 模式——官方模块之间用 29.6 × 1.5 的榫舌在厚度 ≈7.3 处互卡，
Mosaico 侧面**很可能**有配合的槽；**到货看见槽再启用**，那是乐鑫自己的定位方式，零压屏。

**「两侧边缘会不会高出 Mosaico 影响手感？」** v0.2 会（远端唇 13.7，高出屏面 2.2 mm，正在拇指那条边上）。
v0.3：远端唇降到 **10.4，低于屏面 1.08**；±X 角柱 4.0；只有压条顶面高出屏面 **0.52 mm**，且只在远端 6 mm 宽一条，
两端立柱在唇**外侧**、不进 Mosaico 脚印。

> **v0.2 变化**（已被 v0.3 部分替代）：① 用官方 3mf 全分辨率底板（用户下载），不再用压缩预览网格；② 坐标改 Z 朝上，
> 导入 Bambu 即平躺；③ **加卡扣**——远端唇覆盖 Mosaico 全厚，顶部两个 8 mm 宽卡舌扣住屏面边缘，
> 过盈 0.5、两侧开缝独立弹，应变 ≈0.6 %（PLA 反复许用 1.65 %）；④ **加滑入止挡**，定义排针插到底的位置，
> 防过推；⑤ **装配顺序写死**，保证排针进 H2 之前 Mosaico 已被两向定位。

## 这是什么

替换官方模块的 3D 打印**底板**。官方底板全部特征原样保留（`import` 官方 GLB 导出的 STL，
与官方外壳的卡合面零改动），再加一块通底托盘把 **Mosaico 也定位住**。
于是 Mosaico 与模块的相对位置由这一块塑料锁死，2×10 排针**只走电、不承力**。

官方原设计里模块悬空挂在排针上——本体重量、按键力、传感器全部经 20 根针进 Mosaico 母座焊点。这正是要改掉的。

```
      ┌──────────────────────────┬───────────────┐
      │  Mosaico（背面朝下）      │  官方模块       │  ← 两者背面同在一个平面
      │  三面唇边框住，中央开空    │  官方 PCB 4 颗   │
      │                          │  M2×6 自攻      │
      └──────────────────────────┴───────────────┘
      ═══════════════ 通底托盘 2.0 mm ═══════════════
```

## 装配（顺序**必须**照做——为了排针）

1. 打印 `extended_baseplate.stl`（PLA，与官方件同参数：0.2 层高、3 壁、25 % 填充）。**打网格版外壳**（alignedcircles），不用买透镜罩。
2. **不打印官方底板**——本件替代它。官方**外壳**照常打印。
3. 官方 PCB 对孔放到本件的模块区（4 个螺柱与官方底板同位），4 颗 M2×6 自攻。
4. 官方外壳对齐卡入（与官方步骤 4 相同——卡合面没变）。
5. 装键盘轴（官方步骤 6；网格版跳过透镜）。
6. **Mosaico 背面朝下、屏朝上，放进唇框的远端**（远离模块那头），落到环形沿上。此时 ±X 角柱定住 X、环形沿定住 Z，
   Mosaico **只剩沿排针轴向一个自由度**。
7. **沿排针方向推向模块，直到碰到止挡条。** 排针此时才进入 H2，进入时针只受轴向力、无横向力。
8. **压条对孔放到远端两根立柱上，拧 2 颗 M2**（用户现有 M2，长 6～8）。压条内侧 0.5 mm 薄唇搭在 Mosaico 前缘，把它压平在环形沿上。
   螺钉方向与排针垂直，排针不受力。**不要拧到压条变形**——载荷只有几牛，拧到手感有阻力即止。

取出反序：先拆压条、抬起远端，再沿排针方向拔离模块。**不要先抬模块那一头**——那会把排针撬弯。

打印两件：`extended_baseplate.stl`（托盘）和 `end_bar.stl`（压条）。

## 用它当夹具能量到的（直接喂轨二）

装好之后不拆，量：
1. 排针从模块外脸露出的长度（→ C1 针头长）
2. 两排针中心到模块前脸／背面的距离（→ H2 两排的 Z 位置，AS-04）
3. 针截面是否 0.64 方（→ 搭接阈值计算）
4. 模块壳实际厚度是否 10.90（→ 与 Mosaico 11.48 的高差）
5. `GAP` 实际值

## 自检

编译时 ECHO 里 `-> OK` 须全绿；`grep -c -- '-> F''AIL'` 为 0。本版：托盘 manifold 74818 面，压条 420 面。

## 不做的事

不改 Mosaico、不改官方 PCB、不改官方外壳。任何在 Mosaico 本体上加胶加卡加螺钉的加固都违反不变量①。
