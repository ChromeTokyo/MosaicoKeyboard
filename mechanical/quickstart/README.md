# 轨一：官方 Module Interaction 加固延伸托盘（v0.4 · 四角螺钉压框）

## v0.4 先认错

用户对 v0.3 的判决：「黑人问号 你这能挡得住谁哦」「你没发现最近产出没人帮你审？全是低级错误」。属实。v0.1～v0.3 没有人复核，逐版错误：

| 版本 | 错在哪 |
| --- | --- |
| v0.1 | U 形框靠两根 5×2 短桥挂着 |
| v0.2 | 卡舌挂在唇顶上方 2.5 mm 空中，扣不到任何东西 |
| v0.3 | 立柱放在唇**内侧**顶进 Mosaico 角落 4.2×4.5；压条本体盖到屏面上方；OpenSCAD 变量先用后定义；「保持」只剩远端一根 0.5 mm 薄唇，模块端除排针无任何约束——Mosaico 可绕排针端翘起，翘起即掰针；远端唇紧贴 Mosaico −Y 面（0.3 间隙），根本没有「先落沿再沿针轴推」的空间；止挡条 1.2 厚伸进外壳脚印 1.0 mm |

v0.4 全部推翻保持方式，本文件、`extended_baseplate.scad` 的 ECHO 自检、以及**另一人独立写的检查脚本**三处互相对照。

## 这是什么

替换官方模块的 3D 打印**底板**。官方底板全部特征原样保留（`import` 官方 3mf 导出的全分辨率 STL，一个面不改），
下面加一块通底托盘，旁边加 **Mosaico 托位**（U 形环形沿 + 四根角柱 + 8 mm 滑入区），另打一块 **压框**（bezel）。
Mosaico 与模块的相对位置由这两块塑料锁死，2×10 排针**只走电、不承力**。

官方原设计里模块悬空挂在排针上——本体重量、按键力、传感器全部经 20 根针进 Mosaico 母座焊点。这正是要改掉的。

```
 −Y（远端）                                                        +Y（模块）
 ┌─┬──────────────────────────────────────┬────────┬──────────────┐
 │墙│ 滑入区 8 │        Mosaico 45.19          │GAP 0.5 │  官方模块    │  ← 压框 1.6 厚压在 Mosaico 四条前缘各 1.0 上
 │ │  (空)    │  背面朝下，落在 U 形沿上        │(排针)  │  PCB+外壳    │     四角 M2 拧进托盘四根角柱
 └─┴──────────┴──────────────────────────────┴────────┴──────────────┘
 ═════════════════════ 通底托盘 2.0 mm（Z −2～0）═════════════════════
```

俯视：Mosaico ±X 面外侧各两根角柱（贴 Mosaico 段 5.9 mm，中央 34 mm 全空），远端两根向 −Y 延长 8 mm 成滑入区导轨，远端墙封口。

## 装配（顺序**必须**照做——为了排针）

1. 打印 `extended_baseplate.stl`（托盘，PLA，与官方件同参数：0.2 层高、3 壁、25 % 填充，无支撑）。
2. 打印 `bezel.stl`（压框）——**顶面朝下**（倒角面贴床、后裙朝上），无支撑。
3. **不打印官方底板**——本件替代它。官方**外壳**照常打印（网格版 alignedcircles，不用买透镜罩）。
4. 官方 PCB 对孔放到本件的模块区（4 个螺柱与官方底板同位），4 颗 M2×6 自攻。
5. 官方外壳对齐卡入（与官方步骤相同——卡合面没变）。装键盘轴。
6. **Mosaico 背面朝下、屏朝上，放进远端滑入区**（四根角柱之间、远端墙前），落到 ±X 导轨上。此时它距针尖 ≥2.5 mm，
   X 由 −Y 两根长块导向、Z 由导轨定住，**只剩沿排针轴向一个自由度**。
7. **沿 +Y 推向模块。** 推进约 5.6 mm 后 +Y 两根角柱也开始导向（两端同时导向），**之后排针才进入 H2**。
   推到排针座到底（用户手感：阻力突增）。默认 GAP 下没有止挡条，见下。
8. **压框对孔放上**（后裙落进滑入区、挡在 Mosaico −Y 面后方），4 颗 M2×6 拧到手感有阻力即止。
   螺钉方向与排针垂直，排针不受力。**不要拧到压框变形**——载荷只有几牛；柱顶比屏面低 0.3，只是拧过头的硬止点。

取出反序：先拆压框，再沿 −Y 拔离模块。**不要先抬任何一边**——那会把排针撬弯。

## 已知风险（自知未解决）

1. **Q1-13 裕量只有 0.09 mm**：+Y 角柱开始导向的位置比排针触及只早 0.09 mm。若实际针尖露出 >6.1 mm，排针会在两端同时导向之前先碰到 Mosaico 面（此时只有 −Y 端 12 mm 长导向，偏摆可达 ~2 mm）。缓解：到货先量 ①，超了就收窄 Q1-6 缺口加长 +Y 角柱，或减 CLR。
2. **无止挡**（默认 GAP）：过推保护只剩排针座本身；与官方裸用相同，但违背 v0.2 的初衷。GAP 实测 ≥1.7 才有条。
3. **压框排针侧那条边只有 1.2 × 1.6**（GAP 0.5 − 让位 0.3 + 压 1.0），跨 43 mm。简支中点 2 N 估算挠度约 2.5 mm（固支约 0.6）。它压住的 +Y 边紧贴模块，手指够不到，实际载荷小；但它是压框最脆的地方，磕碰会断。
4. 压框四角螺钉盘头高出压框顶面约 1.3～1.6（在 Mosaico 脚印外的四角）。未做沉头。
5. 压框整体高出屏面 1.6（用户在 v0.2 时不喜欢远端高出 2.2）；这是压框方案固有的。
6. Mosaico 的 Y 位置由排针座到底定义，不由托盘定义；压框内窗每边 1.0 的压边和后裙 0.8 的间隙是对此的容差。
7. 官方外壳是否落在 Z=0 未证实（Q1-22）：外壳内壁 21.26 小于底板底缘凸边 21.7～21.8，更像是坐在凸边上（顶面 11.4）。本设计对两种情况都不碰，但外壳与 Mosaico 的 0.58 高差说法可能不成立。
8. 导出托盘含 25 个封闭小内腔（官方底板底面刻线被托盘顶面封住）。试过截面回填，Manifold 并集反而不封闭，故保留。
9. 全部未打印、未实配。

## 用它当夹具能量到的（直接喂轨二）

装好之后不拆，量：
1. 排针从模块外脸露出的长度（→ Q1-13、C1 针头长）
2. 两排针中心到模块前脸／背面的距离（→ Q1-14、H2 两排的 Z 位置，AS-04）
3. 针截面是否 0.64 方（→ 搭接阈值计算）
4. 模块壳实际厚度是否 10.90、是否落在底板底缘上（→ Q1-22）
5. `GAP` 实际值（→ Q1-2、止挡）

## 不做的事

不改 Mosaico、不改官方 PCB、不改官方外壳。任何在 Mosaico 本体上加胶加卡加螺钉的加固都违反不变量①。

## ⚠ 2026-09-24 晚：v0.1～v0.4 共有的根错误（审核发现，主控已自核确认）

官方底板的 **排针出口在 +X 边**：Z=1.5 本体截面四边内缩 −X +2.78／**+X 0.00**／±Y +0.56，
且 −X 中央带（|Y|<12.5）再内缩到 −16.82——那是给对侧 2×10 母座的让位；±Y 是螺柱边。
主控从 v0.1 起假设排针从 −Y 边出去、把 Mosaico 放在了螺柱边，四版同错。
"按官方 3mf 坐标约定"这句话从没被任何人核过。**v0.5 起 Mosaico 必须在底板 +X 侧，排针轴 = X。**
