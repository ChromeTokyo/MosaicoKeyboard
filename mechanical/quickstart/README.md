# 轨一：官方 Module Interaction 加固延伸托盘（v0.4 r2 · 四角螺钉压框）

## 先回答三问

**能挡住谁。** Mosaico 四条屏面前缘各被 1.0 mm 宽的压框边盖住，任一角想抬起最多 0.12 mm（名义游隙，见 R1）就顶到压框；想沿排针轴退出最多 0.8 mm 就顶到压框后裙，此时排针还插着 4.7 mm；横向被四根角柱与远端导轨锁在 ±0.15 mm。也就是说：**掰针的三种动作（抬角、拔出、横扭）都被挡住**，排针只走电。挡不住的：Mosaico 本身的 X 位置有 ±0.15 游隙、Z 有 0.12 游隙——这是限位不是夹紧，故意的（夹紧会把螺钉力压进玻璃边，见下）。

**靠什么。** 一块 1.6 mm 厚的闭合压框，4 颗 M2×6 自攻进托盘四根 6.5 mm 方柱（Ø1.7 底孔、深 7）。**压框本体坐在柱顶上（硬止点），螺钉拧到底力全进 PLA 柱，不进玻璃**；压框压边处底面比柱顶再抬一层（0.2），所以对 Mosaico 是「盖住」不是「压住」。Mosaico 的 Y 位置由排针座到底定义（同官方裸用），托盘不另设止挡（GAP 0.5 里放不下 1.2 壁，几何上不可能，见 Q1-10）。

**高出多少。** 托盘任何部分不高于屏面（柱顶 11.40，屏面 11.48）。压框顶 13.0，**高出屏面 1.52**，三边外缘 0.5×45° 倒角、排针侧那条 1.2 宽的边不倒角（倒了就只剩 0.7）。四角螺钉盘头再高 1.2（沉台 0.4 已扣），**盘头顶高出屏面 ≈2.7**，位置在 Mosaico 脚印外的四角——硬要求 2 字面只放行压框本身，这一项**需用户认可**；换 M1.4 盘头则 ≈2.2。

## 这是什么

替换官方模块的 3D 打印**底板**。官方底板全部特征原样保留（`import` 官方全分辨率 STL 后旋转 −90°，一个面不改），下面加通底托盘，旁边加 **Mosaico 托位**（闭合环形沿 + 四根角柱 + 8 mm 滑入区 + 远端短墩），另打一块 **压框**（bezel）。Mosaico 与模块的相对位置由这两块塑料锁死，2×10 排针**只走电、不承力**。官方原设计里模块悬空挂在排针上——本体重量、按键力、传感器全部经 20 根针进 Mosaico 母座焊点，这正是要改掉的。

```
 −Y（远端）                                                              +Y（模块）
 ┌┐ 手指口 28 ┌┐
 │墩│ 滑入区 8 │          Mosaico 45.19（背面朝下落在闭合沿上）        │GAP 0.5│  官方模块        │ ← 压框 1.6 盖住四条前缘各 1.0
 │ │  (空)    │                                                        │(排针) │  PCB+外壳（坐台阶）│    四角 M2 拧进四根角柱，压框坐柱顶
 └─┴──────────┴────────────────────────────────────────────────────────┴───────┴──────────────────┘
 ══════════════════════════ 通底托盘 2.0 mm（Z −2～0）══════════════════════════
```

俯视：Mosaico ±X 面外各两根角柱（贴 Mosaico 段 5.745，中央 34 mm 全空给功能面），远端两根向 −Y 延长 8 mm 成滑入区导轨，两端短墩是落位止面，中央 28 mm 空着让手指进去推。

## 装配（顺序**必须**照做——为了排针）

1. 打印 `extended_baseplate.stl`（托盘，PLA，与官方件同参数：0.2 层高、3 壁、25 % 填充，无支撑；切片器会把官方底板底面刻线形成的 25 个 0.5 深小内腔当空腔，正常）。
2. 打印 `bezel.stl`（压框）——**顶面朝下**（倒角面与沉台贴床、后裙朝上），无支撑（闸门 #9 按此朝向判过：首层无 <0.8 条、逐层无 >2 悬空）。
3. **不打印官方底板**——本件替代它。官方**外壳**照常打印。
4. 官方 PCB 对孔放到本件的模块区（4 个螺柱与官方底板同位），4 颗 M2×6 自攻。**PCB 排针那一边要朝托盘的 Mosaico 托位**——托盘只有这一个方向能放（底板螺柱不对称）。
5. 官方外壳对齐卡入（卡合面没变，外壳坐在底板台阶上）。装键盘轴。
6. **Mosaico 背面朝下、屏朝上，放进远端滑入区**（四根角柱之间、靠到两端短墩），落到闭合沿与导轨上。此时它距针尖 2.65 mm，X 由 −Y 两根长块导向、Z 由沿定住，只剩沿排针轴向一个自由度。
7. **指尖从远端手指口顶住 Mosaico −Y 面，沿 +Y 推。** 推进 2.55 mm 后 +Y 角柱的导入斜角开始接 Mosaico 角、2.65 mm 后针尖触面——**两者几乎同时**（裕量 0.095，见 Q1-13），所以推之前**目视把 Mosaico 侧槽对准排针**，轻推到有阻力再加力；导轨只锁横向 ±0.15、偏摆 ≤1.55°，+Y 面最多歪 1.22 mm（半针距 1.27）。总行程 8.15 mm，推到排针座到底（阻力突增）。默认 GAP 下没有止挡条。
8. **压框对孔放上**（后裙落进滑入区、挡在 Mosaico −Y 面后方 0.8），4 颗 M2×6 **拧到压框坐实柱顶**——螺钉力全部进 PLA 柱，压框只是盖住 Mosaico 前缘（游隙 0.12），拧再紧也不会压玻璃。

取出反序：先拆压框，再从手指口/±X 窗口捏住沿 −Y 拔离 5.5 mm 针脱开、再 2.65 到墩，然后才能上提。**不要先抬任何一边**——那会把排针撬弯。

想零游隙（不晃）：在压框四条压边底面贴一层 0.1～0.2 mm 胶带，限位就变成轻压；别贴厚的（>0.3 会让压框坐不到柱顶，回到 F3 的问题）。

## 三条 WARN 与已知风险（请拍板／到货验证）

1. **盘头高出屏面 2.7**（#3）：硬要求 2 字面只放行压框 ≤1.6。四角、脚印外。要么认可，要么用户改 M1.4（2.2）或沉头螺钉（本版沉台留 1.2 底，不敢再挖）。
2. **无止挡**（#10）：硬要求 5 写「推到止挡」，GAP 0.5 里放不下任何可打印挡条；插入深度由排针座到底定义，同官方裸用。GAP 实测 ≥1.55 自动生成。
3. **导向不先于针尖**（#11）：裕量 0.095 由 (45.19−34)/2 − 5.5 决定，只有收窄 Q1-6 的 34 mm 才能改；CLR 0.15 与导入斜角只把偏摆压到 1.22 mm。装配必须目视对准，同官方裸用。PIN_LEN 未实测。
4. 压框排针侧那条边 1.2×1.6 跨 43 mm、不倒角：是连接筋不是承力边（简支中点 1 N 挠 1.6 mm），磕碰会断、断了会掉进排针区。+Y 边的盖住由 ±X 两条的角部完成（螺钉离 +Y 面 3.1 mm）。
5. AS-01 厚度 11.48 未实测：压框可用窗口 11.30～11.65；薄了松、厚了坐不到柱顶（那就是螺钉力进玻璃）。到货先量厚度再打压框。
6. GAP 实际 >1.3 整个压框放不下（后裙顶到 Mosaico）；<0 不可能。GAP 由排针塑壳是否突出外脸决定，到货塞尺量。
7. +Y 角柱离外壳 −Y 面 0.3、离外壳 X 脚印 0.19：外壳若靠下缘向外弹 >0.2 卡合，会被角柱顶住（外壳 STL 上没看到卡扣，但装配指南写「卡入」）。
8. 官方 PCB 排针塑壳若突出模块外脸（右角排针本体 2.5 厚，PCB 边到外脸距离未知）则 GAP 下限不是 0；会直接改变 Q1-2。
9. 托盘中央 34 mm 段只剩两条 10.5×2 底板条连接两端，扭转刚度低——桌面用可接受，手持不行（轨二的事）。
10. 全部未打印、未实配。M2 自攻进 Ø1.7 PLA 孔的手感、外壳卡合、Mosaico 背面是否平，都要到货看。

## 用它当夹具能量到的（直接喂轨二）

装好之后不拆，量：
1. 排针从模块外脸露出的长度（→ Q1-13、C1 针头长）
2. 两排针中心到模块前脸／背面的距离（→ Q1-14、H2 两排的 Z 位置，AS-04）
3. 针截面是否 0.64 方（→ 搭接阈值计算）
4. 模块壳实际是否坐在底板 1.2 台阶上、顶面 12.1（→ Q1-22）
5. `GAP` 实际值与排针塑壳是否突出外脸（→ Q1-2、止挡）
6. Mosaico 实测厚度（→ AS-01、压框 LIP_RECESS）

## 不做的事

不改 Mosaico、不改官方 PCB、不改官方外壳、不改官方底板的任何一个面。任何在 Mosaico 本体上加胶加卡加螺钉的加固都违反不变量①。
