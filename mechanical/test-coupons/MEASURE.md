# 公差阶梯标定件 —— 打印与测量指引

## 0. 这盘东西解决什么问题

外壳上的滑配、卡扣、孔柱配合、限位高度这几处，如果按「打一版 → 试 → 改一个数 → 再打一版」
收敛，每轮都是小时级，比额度慢得多，是整个项目真正的节奏瓶颈。

这盘把「改一个数再打一次」换成「一次把这个数的一整排值都打出来」。
打一次、量一遍，就同时得到五组配合的实测值；之后所有壳体文件只需要把量到的数填进参数表，
**不必再为找配合而反复打印**。剩下的打印只用来验证形状和手感，不用来试公差。

这盘**不依赖主板尺寸，也不依赖 Mosaico 实物**——它量的是打印机，不是产品。
所以它现在就能打，不用等任何东西。

## 2. 打印设置（必须照做，否则量到的是切片参数不是打印机能力）

| 项 | 值 | 为什么 |
| --- | --- | --- |
| 喷嘴 | 0.4 mm | 与最终壳体一致 |
| 层高 | 0.2 mm | 同上 |
| 壁 | 3 圈 | 同上 |
| 填充 | ≥ 20 % | 低于此值 D 组卡爪根部刚度失真 |
| 水平膨胀 / XY 补偿 | **保持默认，不要为这盘调** | 这盘的目的就是量出默认值下的偏差 |
| brim | **不加** | brim 改第一层轮廓，会污染 A 组高度与 B 组直径 |
| 材料 | 与最终外观件同一卷 | 见下方说明。**用 PLA-CF 前必须先换硬化喷嘴**，否则 A/B 两组量到的是喷嘴磨损过程 |

**关于材料**（详见 `mechanical/MATERIALS.md`）：用户拟用 PLA-CF。
A／B／C 三组按最终外观件的料（PLA-CF）打。
**D 组与 E 组建议 PLA-CF 与 PETG 各打一份**——件很小，多打一份成本几乎为零，
但能直接证实或推翻 `MATERIALS.md` 第 2.1 节的结论
（PLA-CF 的许用应变 ≈ 0.45 %，而 0.3 mm 过盈的卡扣根部应变 = 0.50 %，按算是不够的）。

**卡尺没到也能先做 C／D／E 三组**——它们全是手感判断（能不能徒手插入、有无卡滞、
有无「咔」的到位感、手掰断不断），不需要量具。只有 A 组（高度）与 B 组（柱径）要卡尺。

## 3. 逐组测量

### A 组 · 高度重复性（**这盘里最值钱的一组**）

五个标称 10.00 mm 的方柱，摆在盘面四角与中心，侧面刻 A1…A5。**不要打磨顶面。**

用卡尺量每个的实际高度，各量 3 次取中位数：

| 件 | 实测高度 mm |
| --- | --- |
| A1（左前） | |
| A2（右前） | |
| A3（右后） | |
| A4（左后） | |
| A5（中心） | |

算两个数：

- **系统偏差** = 五个的均值 − 10.00 → 可以在模型里一次性补偿掉，不是公差。
- **一致性** = （最大 − 最小）/ 2 → 这就是壳体足底面高度的实际公差。

**为什么最值钱**：`MATING.md` 第 5.3 节刚算清楚，弹簧针全行程要求由 Y 向公差链
`t` 决定，关系是 `S ≥ 3(2t + m)/2`。现在 `t` 取的是**假设值 ±0.15**（`AS-31-mm-18`），
足底面只是这条链里的一项，整链假设为 ±0.50，于是要求全行程 2.0 mm。
如果实测下来这台机器的一致性优于假设，整链能压到 ±0.25，全行程要求直接降到 1.2 mm，
**弹簧针选型从"只能挑常见区间的上沿"变成"随便挑"**。反过来若实测更差，现在就知道，
而不是等打完壳体装上才发现压不到位。

### B 组 · 小圆柱直径偏差

六根柱，底座上刻 1…6，对应标称 1.95 / 2.00 / 2.05 / 2.10 / 2.15 / 2.20 mm。
逐根量实际直径（量根部以上 3 mm 处，避开第一层的象脚）：

| 序号 | 标称 | 实测 | 偏差 |
| --- | --- | --- | --- |
| 1 | 1.95 | | |
| 2 | 2.00 | | |
| 3 | 2.05 | | |
| 4 | 2.10 | | |
| 5 | 2.15 | | |
| 6 | 2.20 | | |

用途：模块板与主板的定位孔是 PCB 工艺的 Ø2.2（准），壳体侧的柱是打印件。
有了这条偏差曲线，就能反推「要得到实际 Ø2.10 的柱，模型里该画多少」。

**不要**把柱插进打印出来的孔里试——打印孔本身也不准，那是拿两个误差互相量。

### C 组 · 滑配间隙（模块组件落入底座槽）

六个槽刻 1…6，对应间隙 0.10 / 0.15 / 0.20 / 0.25 / 0.30 / 0.35 mm；轨只有一根，共用。

对每个槽，把轨插进去来回滑十次，记录：

| 序号 | 间隙 | 徒手能否插入 | 滑动有无卡滞 | 到底后横向晃动 |
| --- | --- | --- | --- | --- |
| 1 | 0.10 | | | |
| 2 | 0.15 | | | |
| 3 | 0.20 | | | |
| 4 | 0.25 | | | |
| 5 | 0.30 | | | |
| 6 | 0.35 | | | |

取「能顺滑滑动、晃动最小」的一档。落入式结构宁可稍松——保持力由卡扣提供，不靠滑配的紧度。

### D 组 · 卡扣过盈量

四根悬臂卡爪刻 1…4，对应过盈 0.20 / 0.30 / 0.40 / 0.50 mm；被扣板一块，共用。

| 序号 | 过盈 | 有无「咔」的到位感 | 单手能否压入 | 反复 10 次后爪根 |
| --- | --- | --- | --- | --- |
| 1 | 0.20 | | | |
| 2 | 0.30 | | | |
| 3 | 0.40 | | | |
| 4 | 0.50 | | | |

爪根发白或出现裂纹即为应力过高，须加厚爪根或换材料。PETG 与 ABS 结果差别明显，
**务必用最终要用的那卷料打**。

### E 组 · 壁厚与最小特征

五片立壁 0.8 / 1.0 / 1.2 / 1.6 / 2.0 mm，从左到右。

| --- | --- | --- | --- |
| 0.8 | | | |
| 1.0 | | | |
| 1.2 | | | |
| 1.6 | | | |
| 2.0 | | | |

`module_shell.scad` 里 `SHELL_MIN_W = 1.2` 是假设，这组给它实测依据。

## 4. 量完之后

把上面五张表填好回给主控。主控会把结果写进：

- `module_board.scad` 的 `DOCK_Y_TOL`（A 组）→ 连带重算 `MATING.md` 第 5.3 节的弹簧针行程窗口
- `module_shell.scad` 的定位柱标称直径（B 组）
- `dock_shell.scad` 的落入槽滑配间隙（C 组）
- `dock_shell.scad` 与 `module_shell.scad` 的卡扣过盈（D 组）
- `module_shell.scad` 的 `SHELL_MIN_W`（E 组）

**这五处填完，外壳的公差就不再是假设了**，后续打印只需验证形状与手感。
